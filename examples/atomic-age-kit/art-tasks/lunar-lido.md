# lunar-lido

- 用途：着陆页「画廊指南」卡片二：月面浴场（展览立体模型）
- 位置：`site/index.html #visit .fg-card [data-task=lunar-lido]`
- 尺寸：1600×1000 px，JPG 或 PNG（不透明）
- 安全区：x 120–1480, y 80–920
- 留给 UI 的空白：
  - 卡片在页面里按 16:10 显示，四周有 3px 炭黑框
  - 手机宽度下同比缩放，不裁切
- 光：黑色天空，地球从左上方照亮场景（冷光），浴场的泳池灯在穹顶内发出暖光
- 色板：奶油纸 #EAD5B0、炭黑 #211E1B、青 #17555B、朱红 #C4421D（主色，面积不超过 25%）、芥黄 #E8922A；其余颜色降饱和，整体像 1960 年代胶印
- 风格参考：1950–60 年代太空时代杂志插画与旅游海报的画法：平涂色块、少量喷笔渐变、可见的网点与轻微套色错位、纸张老化；建筑是 Googie 式（悬挑屋顶、斜柱、星芒招牌、回旋镖形水池）；参考方向：1960 年代航空公司与世博会海报、中世纪现代建筑摄影、NASA 1960–70 年代的概念插画
- **原创设计；不出现真实标志、国徽、品牌字标和可辨认的真实人物。写实场景只由图像模型出图，不用代码画（#301）。**
- 交回：放到 `art/lunar-lido.jpg`，在 materials 项目里 `materials add --kind generated --tool <模型> --prompt materials/requests/lunar-lido.md` 登记后，可再 `materials process --effect duotone` 印成双色网点；页面里把 `.art-slot` 里的 `svg.slot-show` 换成同宽高比的 `<img>`，保留 `alt`，并在 `art/provenance.json` 记一条。
