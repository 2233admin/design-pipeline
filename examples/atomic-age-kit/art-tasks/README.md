# 出图任务单

着陆页里没有合适公有领域年代图片的两个美术位，各一份任务单：尺寸、安全区、留给 UI 的空白、光、色板、风格参考、负面约束，最后是可以直接交给图像模型的提示词。`tasks.json` 是同样内容的机器可读版本。

页面里的美术位（`.art-slot`）都带 `data-task`，值就是下表的任务 id。默认是展示模式：用平涂色块和线条做的示意构图（不画写实建筑、人物、载具）；`site/index.html?slot=1` 显示占位模式（斜纹、任务 id、尺寸与任务单路径）。

模板里的其它美术位用的是 NASA 1964–1975 年的公有领域图片，经 `materials process` 印成双色网点或复印，来源与参数见 `../art/provenance.json`。
