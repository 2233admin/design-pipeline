# frame-04

- 用途：闸甲档案：闸甲肆号（SLUICE FRAME 04）全身立绘（封存状态）
- 位置：`templates/site.html #s-frames .cc-frame [data-task=frame-04]`
- 尺寸：1200×1600 px，PNG（透明背景）
- 安全区：x 72–1128, y 96–1504；整机入画
- 留给 UI 的空白：
  - x 0–1200, y 1300–1600：名牌条，只放地面
  - 手机宽度下按 3:4 居中显示
- 光：顶光（冷白、很平），几乎没有轮廓光；整体低饱和，像封存仓库里的灯
- 色板：void #000000、面板 #0D0906、主色红橙 #E8380D（面积不超过 8%）、数据琥珀 #F2A93B（只做灯与读数）、警报红 #B0081F、屏幕蓝 #2B4F69；其余颜色降饱和
- 风格参考：原创 90 年代赛璐璐电视动画的写实设定画法：干净的细描边、2–3 阶硬阴影、少量喷笔高光，工业感强（铆接钢板、液压管、排水泵、混凝土闸墙、警示漆）；参考方向：大型排涝泵站与船闸的工程照片、70 年代重型机械与水利工程图纸、雨夜的城市排水设施
- **原创设计，不得出现任何现有作品的角色、机体或标志。机甲、人物一律由图像模型出图，不用代码画。**
- 交回：放到 `materials/generated/frame-04.png`，用 `materials add --kind generated` 登记，再按 `layers.json` 的层序合成；页面里对应 `.cc-slot` 换成同宽高比的 `<img>`，保留 `alt`。
