# surge-feed

- 用途：警报墙右侧实时影像：声呐影像中的涌体
- 位置：`templates/site.html #s-alert .cc-s2__feed [data-task=surge-feed]`
- 尺寸：1600×900 px，PNG 或 JPG（不透明）
- 安全区：x 160–1440, y 72–828；主体在中央三分之一
- 留给 UI 的空白：
  - x 0–1600, y 760–900：页面在影像下沿叠信息条，这里只放暗部
  - 中心 96×96 区域会叠一个十字准星，不要把主体的关键细节放在正中
- 光：没有自然光：画面是声呐与热成像混合的伪彩色，主体用琥珀 #F2A93B 等高线描出，背景是深屏幕蓝 #18324A，带扫描线
- 色板：void #000000、面板 #0D0906、主色红橙 #E8380D（面积不超过 8%）、数据琥珀 #F2A93B（只做灯与读数）、警报红 #B0081F、屏幕蓝 #2B4F69；其余颜色降饱和
- 风格参考：原创 90 年代赛璐璐电视动画的写实设定画法：干净的细描边、2–3 阶硬阴影、少量喷笔高光，工业感强（铆接钢板、液压管、排水泵、混凝土闸墙、警示漆）；参考方向：大型排涝泵站与船闸的工程照片、70 年代重型机械与水利工程图纸、雨夜的城市排水设施
- **原创设计，不得出现任何现有作品的角色、机体或标志。机甲、人物一律由图像模型出图，不用代码画。**
- 交回：放到 `materials/generated/surge-feed.png`，用 `materials add --kind generated` 登记，再按 `layers.json` 的层序合成；页面里对应 `.cc-slot` 换成同宽高比的 `<img>`，保留 `alt`。
