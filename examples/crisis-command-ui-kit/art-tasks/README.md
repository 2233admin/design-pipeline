# 出图任务单

示例站和两屏应用里每个美术位一份任务单：尺寸、安全区、留给 UI 的空白（按页面里的框换算成出图像素）、光、色板、风格参考、负面约束，最后是可以直接交给图像模型的提示词。`tasks.json` 是同样内容的机器可读版本，`layers.json` 写每个美术位合成进页面的层序（#311 的层角色）。

页面里的美术位（`.cc-slot`）都带 `data-task`，值就是下表的任务 id。默认是展示模式：空监视器（网格 + 十字准星），不放角色、不放机体；`site.html?slot=1` 显示占位模式（斜纹、安全区虚线、任务 id 与尺寸）。

**所有任务都是原创设计，不得出现任何现有作品的角色、机体或标志。机甲和人物只由图像模型出图，不用代码画（#301）。**
