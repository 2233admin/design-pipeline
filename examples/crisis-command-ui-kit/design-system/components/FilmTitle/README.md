# FilmTitle

Film title: one centred line of heavy Mincho compressed to 0.40, a colon, a mark, and a compressed English caption.

## Provide

Line, mark, caption; tone `--alert`, `--deep` or `--ink`; `--film-size`.

## Use

Product or campaign titles, the logo lock-up of a site.

## States

- Static.

## Don't

- Do not compress beyond 0.40 with this face (its horizontals thin out).
- One colour per title.
