# Toast

Toast: a dark strip with a coloured edge, an icon, a bilingual message, the time and a close button.

## Provide

Kind (alert or info), message, time.

## Use

Events that need no decision.

## States

- Alert: `role=alert`, red edge.
- Info: `role=status`, amber edge.
- Floating toasts close after 6 s.

## Don't

- Do not stack more than three.
