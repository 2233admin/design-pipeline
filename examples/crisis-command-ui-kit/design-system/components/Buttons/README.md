# Buttons

Buttons: primary (amber), alert (red-orange) and ghost, each with a Mincho label and an English caption, cut at one corner.

## Provide

Label, caption, kind, optional icon.

## Use

Primary for the one forward action; alert for an action that changes a danger state; ghost for the rest.

## States

- Hover: one step brighter.
- Pressed: 1px down.
- Focus: 2px outline, the cut drops.
- Disabled: `panel-raised`, `ink-dim`.
- Loading: `aria-busy`, a stepping bar.

## Don't

- Do not round corners.
- Not two primaries side by side.
