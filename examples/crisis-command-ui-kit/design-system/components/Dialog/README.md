# Dialog

Dialog: a red-orange head with stripes, a body with key-values and a footer with cancel and confirm.

## Provide

Title, body, values, actions.

## Use

Confirming a danger action.

## States

- Opens modal (`showModal`); Esc closes.
- Confirm shows loading, then closes and posts a toast.

## Don't

- Do not use for information without a decision.
