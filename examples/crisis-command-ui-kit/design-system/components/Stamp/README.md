# Stamp

Stamp: two heavy Mincho characters in a double frame, cut by horizontal hairlines.

## Provide

Two characters; tone (default on alarm, `--amber`, `--alert`, `--ink`); `--sm`.

## Use

Alarm panels (警报), vote results (可决 / 否决), archive states (封存).

## States

- Static.

## Don't

- Never more than two characters.
- Do not use it as a button.
