# RatioReadout

Ratio readout: a bracket label, a capsule-digit percentage, a bar with the threshold mark and a threshold line.

## Provide

Value, fill (0-1), threshold (0-1).

## Use

Coupling, load, any value with a cut-off.

## States

- Above threshold: amber.
- Below threshold (`is-low`): red-orange.

## Don't

- Do not show more than one ratio this large per view.
