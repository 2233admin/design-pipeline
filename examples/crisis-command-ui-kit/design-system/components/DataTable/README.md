# DataTable

Sluice table: code, name, a status tag and a load bar; the breached row in red-orange, a serviced row dimmed.

## Provide

Rows (code, name, state, load).

## Use

Lists of gates, units, sectors.

## States

- Row hover: `panel-raised`.
- Breach row: `alert-ink`.
- Service row: `ink-dim`.

## Don't

- Do not colour whole rows.
