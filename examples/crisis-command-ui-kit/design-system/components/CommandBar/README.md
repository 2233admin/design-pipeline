# CommandBar

Command bar: the mark and organisation, the nav with a red underline on the current item, the local clock and the state badge.

## Provide

Nav items; current item; state.

## Use

The top of every page.

## States

- Hover: `panel-raised`.
- Current: `alert` underline and caption.
- Danger: the state badge fills red.
- Under 760px the nav becomes a drawer behind the menu button.

## Don't

- Do not add a second row.
