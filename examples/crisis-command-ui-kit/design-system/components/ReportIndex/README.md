# ReportIndex

Report index: title cards as a grid, the current one on paper; a card opens the report dialog.

## Provide

Reports (number, three title parts, synopsis); the current one.

## Use

Episode, chapter or bulletin indexes.

## States

- Hover: the card turns paper.
- Current: paper card, amber meta.
- Focus: inset `focus-ring`.

## Don't

- Keep every card a full title card (no thumbnails).
