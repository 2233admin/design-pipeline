# StatusPlate

Status plate: big Mincho over English on a cut-corner plate; lit in amber with stripes in the corner, or dark.

## Provide

Chinese, English; lit or not.

## Use

Power source, sortie state, one-of-two states.

## States

- Lit: `amber` fill, `on-amber` type, stripes.
- Unlit: `panel` with `amber-dim`.

## Don't

- Never light both plates of a pair.
