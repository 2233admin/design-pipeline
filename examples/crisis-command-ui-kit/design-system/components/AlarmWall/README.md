# AlarmWall

Alarm wall ground: the screen blue with a 45° lattice and scanlines that hexagon panels sit on.

## Provide

Children (hexagons); `.cc-scan` adds the scanlines and the shimmer.

## Use

Alarm screens only.

## States

- Live: the scanlines shimmer every `dur-flicker`.
- Reduced motion: still.

## Don't

- Never under a type card.
- Do not tint the lattice with the hot colour.
