# Vote

Five-seat vote: five square stamps (可 / 否), one per seat, with each seat's reason under it and the result.

## Provide

Five seats (name, verdict, reason); state done or pending.

## Use

Consensus or approval steps that need several sign-offs.

## States

- Hover: `panel-raised`.
- Focus: `focus-ring`.
- Dissent: `alert-ink`.
- Pending: `aria-busy` seats with a stepping bar; resolves one by one.
- Disabled: `ink-dim`.

## Don't

- Do not reduce to three seats: the five-seat vote is this kit's own sign.
- Do not colour approvals green.
