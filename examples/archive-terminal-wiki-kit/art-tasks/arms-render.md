# arms-render

- 用途：武装道具图（12 件，逐件出）
- 位置：`templates/list.html .at-card--square .at-slot、表格图标（缩到 32px）`
- 尺寸：800×800 px，PNG（透明背景）
- 安全区：武器整体落在 x 80–720, y 80–720 的对角线带内，从左下到右上 45° 摆放
- 留给 UI 的空白：
  - y 680–800：卡片下方另起一栏，图里不放东西
  - 缩到 32px 时仍要认得出：轮廓清楚，不要细碎的小零件凸出
- 光：顶光略偏左，金属有一道冷白高光；强调黄只出现在握把缠绳或小部件上
- 色板：ink #111827、霜灰 #E9EDF1、纸白 #F4F5F6、强调黄 #F2CC00（面积不超过 10%）、信号青 #00C7BD（只做小面积光点）
- 风格参考：原创冷地写实动画插画：干净的细描边 + 3 阶赛璐璐阴影，材质写实（帆布、皮革、拉丝金属、结霜的织物），工业极地装备（防寒外套、护目镜、绳索、工具挂件）；参考方向：极地科考站与破冰船的工业设计照片、20 世纪测绘仪器、雪地工作服的结构与磨损
- **原创角色与物件，不得出现任何现有作品的内容。**
- 交回：放到 `materials/generated/arms-render.png`（或按清单逐张编号），再把模板里对应 `.at-slot` 换成 `<img>`，保留同样的宽高比与 `alt`。
