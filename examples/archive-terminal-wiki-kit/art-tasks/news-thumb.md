# news-thumb

- 用途：动态缩略图（通用）
- 位置：`templates/home.html .at-feed__thumb`
- 尺寸：416×232 px，WebP（不透明）
- 安全区：主体落在 x 32–384, y 24–208
- 留给 UI 的空白：
  - 显示宽度 104px，只保留一个大形状和一处强调色
- 光：与对应文章的头图一致
- 色板：ink #111827、霜灰 #E9EDF1、纸白 #F4F5F6、强调黄 #F2CC00（面积不超过 10%）、信号青 #00C7BD（只做小面积光点）
- 风格参考：原创冷地写实动画插画：干净的细描边 + 3 阶赛璐璐阴影，材质写实（帆布、皮革、拉丝金属、结霜的织物），工业极地装备（防寒外套、护目镜、绳索、工具挂件）；参考方向：极地科考站与破冰船的工业设计照片、20 世纪测绘仪器、雪地工作服的结构与磨损
- **原创角色与物件，不得出现任何现有作品的内容。**
- 交回：放到 `materials/generated/news-thumb.png`（或按清单逐张编号），再把模板里对应 `.at-slot` 换成 `<img>`，保留同样的宽高比与 `alt`。
