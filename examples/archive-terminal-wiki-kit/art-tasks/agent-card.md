# agent-card

- 用途：调查员卡面（通用规则，其余 7 名调查员各出一张）
- 位置：`templates/*.html .at-card .at-slot（3:4）`
- 尺寸：600×800 px，PNG 或 WebP（不透明，背景为 #E9EDF1 到 #F4F5F6 的平涂，不要渐变）
- 安全区：x 40–560, y 40–700；脸部中心落在 y 220–300
- 留给 UI 的空白：
  - y 700–800（600×100）：卡片在立绘下方另起一栏写名字，这里只放躯干与背景
  - x 440–600, y 0–90：右上角会叠一行 9px 等宽小字“// agents”
- 光：同立绘：左上冷白主光，强调黄只做细轮廓光
- 色板：ink #111827、霜灰 #E9EDF1、纸白 #F4F5F6、强调黄 #F2CC00（面积不超过 10%）、信号青 #00C7BD（只做小面积光点）
- 风格参考：原创冷地写实动画插画：干净的细描边 + 3 阶赛璐璐阴影，材质写实（帆布、皮革、拉丝金属、结霜的织物），工业极地装备（防寒外套、护目镜、绳索、工具挂件）；参考方向：极地科考站与破冰船的工业设计照片、20 世纪测绘仪器、雪地工作服的结构与磨损
- **原创角色与物件，不得出现任何现有作品的内容。**
- 交回：放到 `materials/generated/agent-card.png`（或按清单逐张编号），再把模板里对应 `.at-slot` 换成 `<img>`，保留同样的宽高比与 `alt`。
