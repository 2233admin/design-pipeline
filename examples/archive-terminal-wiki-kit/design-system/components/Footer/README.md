# Footer

The footer: a welcome card with the archive mark and three ghost buttons, a row of policy links, the licence line and a build stamp.

## Provide

Site name, contact lines, links, the licence statement and the build id.

## Use

Every page, at the end of the main column.

## States

- Welcome card on `panel-muted`; links `ink-muted`, underlined on hover; build stamp in `mono`.

## Don't

- Do not put navigation that is not in the side nav only here.
- Do not shrink the licence line below 12px.
