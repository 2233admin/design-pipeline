# EmptyState

Empty states: a striped panel with a diamond icon plate, a 中文 line, an ENGLISH caption, a sentence and one action; plus an inline form.

## Provide

The icon, both lines, an optional sentence and an optional action.

## Use

No results, empty discussions, not-yet-recorded content.

## States

- Block form centres the plate and text; inline form sits beside other content with left-aligned text.
- The action is accent when it fixes the emptiness (clear filters, create), ghost otherwise.

## Don't

- Do not blame the reader in the copy.
- Do not show an empty state and results at the same time.
