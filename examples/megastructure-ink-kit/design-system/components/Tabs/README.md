# Tabs

Bilingual tabs with a 2px `signal` underline on the selected one.

## Provide

Tab labels (中文 + caps), the selected index, disabled indexes.

## Use

To filter a list (通讯分类) or switch terminal pages; arrow keys move between tabs.

## States

- Hover: `panel-hover`.
- Selected: `signal` label and underline.
- Disabled: `text-faint`, not focusable by click.

## Don't

- Do not wrap tab labels on desktop.
