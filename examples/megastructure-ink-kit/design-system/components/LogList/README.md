# LogList

Dated transmissions: date, kind, title and code in a hairline list, with a pager.

## Provide

The log entries; the pager's current page and total.

## Use

On the transmissions screen; the kind tabs filter it.

## States

- Hover: `panel-hover`, title to `signal-strong`.
- Current page: `signal` edge and number.
- Disabled pager arrow: `aria-disabled`, `text-faint`.

## Don't

- Do not add thumbnails to rows; one featured card carries the picture.
