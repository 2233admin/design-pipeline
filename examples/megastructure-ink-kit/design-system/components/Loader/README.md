# Loader

Progress: a 6px track, a `line` fill and a `signal` head that scans across every 4.2 s.

## Provide

Label, caps line, percentage.

## Use

For queues and solvers; the button-level loading state is in Buttons.

## States

- It is a `progressbar`; the scan stops under reduced motion.

## Don't

- Do not show a spinner: the grammar scans.
