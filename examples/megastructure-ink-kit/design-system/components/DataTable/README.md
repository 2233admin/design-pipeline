# DataTable

A table of strata: depth range, bilingual name, a state square (off, ok, live, alarm).

## Provide

Rows with range, name and state.

## Use

For reference data on the world screen.

## States

- Hover row: `panel-hover`.
- Current row: a `signal-dim` hairline; live state blinks.

## Don't

- Do not use colour alone: every state also has its word.
