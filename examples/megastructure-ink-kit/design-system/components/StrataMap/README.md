# StrataMap

A cross-section diagram: bands sized by depth, two shafts and a `signal` diamond for you-are-here.

## Provide

The strata list.

## Use

On the survey terminal and wherever the depth story needs a picture that is a diagram, not an illustration.

## States

- Current band: a 2px `signal` inset; alarm band name in `alarm`.

## Don't

- Do not draw rooms or objects inside the bands.
