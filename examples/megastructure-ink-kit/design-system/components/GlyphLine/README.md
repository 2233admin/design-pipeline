# GlyphLine

The kit's own rail script: each character becomes a stack of square bars hung on a baseline rail, always followed by its reading.

## Provide

The text to draw and the reading shown beside it; a height in px.

## Use

As a signature mark: the brand, a member's name, a kicker, footer stamps and the switchboard stream.

## States

- Static. The glyphs are `aria-hidden`; the reading carries the meaning.

## Don't

- Never use the glyphs alone for information.
- Do not copy any existing invented script; the generator in `templates/glyphs.js` is the only source.
