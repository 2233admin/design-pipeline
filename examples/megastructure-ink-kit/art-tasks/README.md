# 出图任务单

每个美术位一份任务单（`<id>.md`），`tasks.json` 是机器可读版本。展示模式下，这些位置画程序生成的结构版（不画人）；`?slot=1` 显示尺寸、安全区和任务编号，等出图后按 `layers/` 的层契约合成。

**所有任务都是原创，不得出现任何现有作品的角色。**
