# Concepts

1. **A line stops at two gates, each gate turns green, and the line lands as the dot that
   completes the name.** (chosen)
   Carrier: the line head, which travels, pauses at each gate and swells into the dot.
   Look: near-black stage, status green, JetBrains Mono wordmark. Tools: HTML/GSAP composition,
   Strudel score. No missing licenses.
2. **Scattered marks snap onto a grid and lock.** Assembly into a logo on a hit.
   Rejected: it says "design system", which any design tool could claim, not "checked before
   anyone sees it".
3. **A red cross flips to a green check beside the name.** Rejected: a literal status icon
   reads as a to-do app, and the flip is a swap, not a movement.

Why 1: the mark is the product's mechanism, so its motion is its meaning. The same geometry
closes the product film (`product-pv/design-pipeline-promo-20s`), so the brand is one object
across both.
