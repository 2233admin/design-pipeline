## 出图规则（按顺序执行，每一步都按条件走，不跳步）

### 1. 先数字数，决定版式

把 `content.md` 里要出现的文字（不含 `#` 开头的标题行和 `>` 开头的说明行）去掉空白和标点后数字数，记为 N。

- 交付物是网页首屏（`hero.html`）：走“首屏版式”。
- 否则，N ≤ 40：走“大字版式”。标题用 112px，标题宽度占画布宽度的 60% 到 80%（不够就换行，不缩字号）；其余文字只用 24px 和 20px。
- 否则，40 < N ≤ 180：走“图文版式”。标题用 72px；说明性的句子放进一块 `surface` 面板，面板宽 = 画布宽 − 128px，内边距 32px；其余文字 24px 和 20px。
- 否则（N > 180）：走“阅读版式”。标题 48px 放在顶部；正文区高度占画布高度的 75%，正文 24px、行高 1.6；装饰全部缩进右上角 160×160px 以内。
- 首屏版式：导航 16px 放在顶部 72px 高的一条里；主标题 72px；副标题 24px，宽度不超过 720px；按钮文字 20px；主标题和按钮都左对齐到 x = 64px。

### 2. 颜色只用这 8 个色值

`#0D0F11` 铺满整个画布；`#171B1F` 只用于面板；`#2C333A` 只用于线和刻度；`#E8EAEC` 是主要文字；`#8B949C` 是次要文字；`#F5A623` 全画面只用在一处（一个词、一个标记或主按钮）；`#36C5C0` 只用于标签和链接；`#E5484D` 不用。
不用渐变、透明度叠色、阴影、发光。

### 3. 装饰锚定在实测文字宽度上

先在浏览器里量出主标题的实际渲染宽度 W（`getBoundingClientRect().width`；SVG 用 `getBBox().width`），装饰尺寸都由 W 算，不凭估计：

- 主标题下方一条强调线：长度 = W，粗 4px，距标题框底边 16px，颜色 `#F5A623`。
- 主标题上方一把刻度尺：共 10 个刻度，总宽 = W，刻度间距 = W / 9，宽 2px；第 3 个和第 7 个高 16px，其余高 8px，颜色 `#2C333A`，底边距标题框顶边 16px。
- 网页首屏不做刻度尺，强调线照做。

### 4. 摆放定律（精确像素）

1. 画布顶部和底部各一条 3px 通栏线，距画布上下边缘 24px，颜色 `#2C333A`。
2. 左上角和右下角（对角）各一块 20×20px 实心方块，外角对齐 64px 安全边距；左上 `#F5A623`，右下 `#36C5C0`。
3. 需要层次时不用阴影，用硬偏移衬底：在文字块后面放一块同尺寸 `#171B1F` 矩形，向右下各偏移 8px，不模糊。
4. 状态标签（例如 `PATCH 3.2`）放在左上方块右侧 16px，JetBrains Mono 20px、大写。
5. 所有文字左对齐到 x = 64px；相邻文字块之间的距离只能是 8 的倍数。

### 5. 出图前自检（8 项全部满足才交付，不满足就改了再查）

1. 画面尺寸正好是 brief 写的尺寸，没有滚动条。
2. `content.md` 的每一行都出现了，没有多字、少字、改字。
3. 没有文字超出 64px 安全边距。
4. 最小字号 ≥ 20px（网页首屏的导航 ≥ 16px）。
5. 只用了第 2 步的色值。
6. 字号只用 112、72、48、32、24、20、16。
7. 强调线和刻度尺的长度等于实测的标题宽度 W。
8. 文件不引用任何外部资源或其他文件。
