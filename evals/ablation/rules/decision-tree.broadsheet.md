## 出图规则（按顺序执行，每一步都按条件走，不跳步）

### 1. 先数字数，决定版式

把 `content.md` 里要出现的文字（不含 `#` 开头的标题行和 `>` 开头的说明行）去掉空白和标点后数字数，记为 N。

- N ≤ 40：走“刊头版式”。刊名用 96px 放在顶部；主标题 64px，标题宽度占画布宽度的 60% 到 80%（不够就换行，不缩字号）；其余文字只用 32px 和 22px。
- 40 < N ≤ 180：走“导读版式”。主标题 64px；导语 44px；其余文字 28px 和 22px。
- N > 180：走“阅读版式”。栏目名 22px 和主标题 64px 放在顶部，占画布高度的 25% 以内；正文区占画布高度的 75%，正文 28px、行高 1.7，每行 18 到 32 个字；段落之间空 24px。

### 2. 颜色只用这 7 个色值

`#F3F4F1` 铺满整个画布；`#FFFFFF` 只用于嵌入的方框；`#121417` 是正文和标题；`#565C61` 是署名、日期、说明；`#0B6E4F` 全画面只用在一处（栏目名、一个关键词或一段引语）；`#F2C230` 只作为一条短语背后的记号笔底色，不做文字颜色；`#CDD2D0` 只用于线。
不用渐变、阴影、透明度叠色。

### 3. 装饰锚定在实测文字宽度上

先在浏览器里量出主标题的实际渲染宽度 W（`getBoundingClientRect().width`；SVG 用 `getBBox().width`），装饰尺寸都由 W 算，不凭估计：

- 主标题上方一条粗线：长度 = W，粗 6px，颜色 `#121417`，底边距标题框顶边 24px。
- 主标题下方一条细线：长度 = W，粗 2px，颜色 `#CDD2D0`，距标题框底边 24px。
- 记号笔底色：高度 = 所在行字号的 40%，贴在这一行的下半部，长度 = 这条短语的实测宽度 + 8px。

### 4. 摆放定律（精确像素）

1. 所有文字左对齐到 x = 88px，右边不超过画布宽 − 88px。
2. 栏目名在主标题上方粗线的上方 16px，22px 加粗，字距 0.1em。
3. 期号和日期放在画布底部，底边距画布底边 88px，22px，`#565C61`。
4. 引语左侧一条 4px 竖线，颜色 `#0B6E4F`，与引语文字间距 24px。
5. 相邻文字块之间的距离只能是 8 的倍数。

### 5. 出图前自检（8 项全部满足才交付，不满足就改了再查）

1. 画面尺寸正好是 brief 写的尺寸，没有滚动条。
2. `content.md` 的每一行都出现了，没有多字、少字、改字。
3. 没有文字超出 88px 安全边距。
4. 最小字号 ≥ 22px。
5. 只用了第 2 步的色值。
6. 字号只用 96、64、44、32、28、22。
7. 两条标题线的长度等于实测的标题宽度 W。
8. 文件不引用任何外部资源或其他文件。
