# 账户设置：个人资料

《纸页》周刊读者账户的设置页，订阅读者在桌面浏览器上打开。
这一屏展示的是：读者改了邮箱但填错了，页面正在提示怎么改，还没保存。只做这一屏。

页面有三块：

- 左侧是分区列表：个人资料、订阅、通知、安全，当前在“个人资料”。
- 右侧是表单，一列，从上到下：
  - 显示名称，输入框里的值是 `林见川`，下面有一句说明。
  - 邮箱，输入框里的值是 `jianchuan@example`。这个值不合格，字段处于出错状态，下面是出错提示。
  - 一个开关“每周五收到新一期的邮件”，现在是开着的，状态用文字“已开启”标出。
  - 危险区：删除账户的后果说明和按钮“删除账户…”。
- 底部是保存栏：提示有未保存的修改，两个按钮“放弃修改”和“保存”。

要求：

- 文字：只用 `content.md` 里的，一字不改，全部都要出现，不加别的字。两个输入框里的值按上面写的填，不算在 `content.md` 里。
- 风格：项目的 `DESIGN.md`。
- 出错状态不能只靠颜色：提示文字必须紧挨着邮箱字段。开关的状态也要有文字。
- 能点的东西要是真的链接或按钮，每个的点击区域不小于 32×32。分区链接指向页内锚点（`#profile`、`#subscription`、`#notifications`、`#security`），每个锚点在页面里都要有对应 id 的元素。输入框用真的 `input` 并带 `label`，开关用真的复选框或按钮。
- 交付：一个文件 `settings.html`，在 1440×900 的浏览器窗口里正好是一屏，不出现滚动条，放在项目根目录。
- 文件自包含：不引用网络资源，也不引用其他文件（字体、图片、脚本库都不行），浏览器直接打开就是成品。
