# 工作台：构建列表

铸台构建监控的工作台页，构建工程师整天开着它，在桌面显示器上看。
一眼要能看出：哪些构建失败了、哪个还在跑、下一步能做什么。只做这一屏。

页面有三块：

- 左侧导航：产品名和四个入口（构建、流水线、机器、设置），当前在“构建”。
- 中间是项目“方舟计划”的构建列表：三个筛选（全部、失败、进行中），表头四列（编号、分支、状态、用时），四行构建。失败的那一行带“重新运行”。
- 右侧是所选机器组“主机组 B”的面板。这组机器还没有跑过构建，所以这里是空状态：说明这里会出现什么，并给出一个下一步动作“接入流水线”。

要求：

- 文字：只用 `content.md` 里的，一字不改，全部都要出现，不加别的字。
- 风格：项目的 `DESIGN.md`。
- 状态（成功、失败、进行中）不能只靠颜色区分，文字标签必须在。
- 能点的东西要是真的链接或按钮，每个的点击区域不小于 32×32。导航链接指向页内锚点（`#builds`、`#pipelines`、`#machines`、`#settings`），“接入流水线”指向 `#connect`，每个锚点在页面里都要有对应 id 的元素。筛选和“重新运行”用按钮。
- 交付：一个文件 `workbench.html`，在 1440×900 的浏览器窗口里正好是一屏，不出现滚动条，放在项目根目录。
- 文件自包含：不引用网络资源，也不引用其他文件（字体、图片、脚本库都不行），浏览器直接打开就是成品。
