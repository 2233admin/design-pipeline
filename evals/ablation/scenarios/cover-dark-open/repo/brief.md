# 封面：版本 3.2 更新日志

《第七区》是一款工厂建造游戏，玩家在废弃的工业区里搭生产线。这是给玩家看的版本更新日志封面，
发在社区和应用商店的更新说明顶部，大多数人在手机上看到它。要让人一眼认出这是《第七区》的大版本更新，标题最醒目。
项目还没有设计规范，风格你来定，要配得上这款游戏。

- 文字：只用 `content.md` 里的，一字不改，全部都要出现，不加别的字。
- 交付：一个文件 `cover.html` 或 `cover.svg`，画面 1080×1440 像素，放在项目根目录。所有文字不小于 20px。
- 文件自包含：不引用网络资源，也不引用其他文件（字体、图片都不行），浏览器直接打开就是成品。
