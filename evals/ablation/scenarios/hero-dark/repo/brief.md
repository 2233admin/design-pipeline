# 官网首屏：铸台构建监控

铸台构建监控的官网首屏，访客是游戏团队的技术负责人，多数在桌面浏览器上打开。
首屏要在几秒内说清产品做什么，并让人愿意点“免费试用”。只做首屏这一屏，不做下面的内容。

- 文字：只用 `content.md` 里的，一字不改，全部都要出现，不加别的字。
- 风格：项目的 `DESIGN.md`。
- 交付：一个文件 `hero.html`，在 1440×900 的浏览器窗口里正好是一屏，不出现滚动条，放在项目根目录。
- 导航和按钮要是真的链接或按钮：链接指向页内锚点（`#product`、`#docs`、`#pricing`、`#login`、`#trial`、`#demo`），每个锚点在页面里都要有对应 id 的元素。
- 文件自包含：不引用网络资源，也不引用其他文件（字体、图片、脚本库都不行），浏览器直接打开就是成品。
