# Add Strudel film scores

Promotional films need music, and the audio gate can only check a track somebody supplies. Agents
can write code, so let them compose the score as code: Strudel patterns render to audio and expose
their exact event grid, so the edit can be timed to real musical events rather than detected
onsets.

Add `film score`: templates or a project pattern, offline rendering, grid export, grid alignment
checks for cuts and accent cues, and license recording. Strudel is AGPL-3.0, so it is installed
into the user's film project on first use and never bundled into this MIT package.
