# Add Game and Web Motion Recipes

## Why

The skill already defines motion purpose, frequency, budgets, reduced motion and interruption review, but a practitioner asking for a health-bar trail or cooldown completion still has to derive a concrete state-and-timing recipe. Motion Reference demonstrates that named product scenarios are a useful discovery layer. The user approved turning these effects into recipes.

## What Changes

- Add four original, locally usable recipes: HP ghost bar, cooldown completion, reward arrival and menu toggle/switch.
- Each recipe explains intent, state/trigger, project-token adaptation, phased timing, platform/semantic primitive choice, rapid-input/cancel behavior, reduced-motion result, source-evidence limits and rendered checks.
- Ship one standalone DOM/SVG browser specimen per recipe, with semantic controls and normal/reduced-motion behavior, so practitioners can inspect and adapt the state changes without a film workflow or runtime install.
- Index the recipes as `kind: doc`, `recordType: method`, `availability: project-owned` in the existing component-source snapshot. Discover with existing unfiltered `design-system search --snapshot`; web component filtering continues to exclude methods.
- Link the small recipe index from existing game/UI and web motion guidance and register packaged resources.

## Existing Contracts Reused

Reuse the catalog v1 normalization/provenance/hash behavior, project MOTION.md, animation opportunity/review, UI transition rules, reference.md/motion.md/qa.md and existing verify interaction/motion. No new dispatcher, CLI, animation runtime, gate, receipt schema or numerical token scale. Technical verification remains separate from Visual Acceptance.

## Impact

Affects packaged references, tools specimens, catalog metadata, guide links and package resources. No upstream source/assets are copied or vendored. Motion Reference remains an attributed observation source; its redistribution license is not asserted. Preserve concurrent ff-tracking and internalize-ui-transition-methods edits.
