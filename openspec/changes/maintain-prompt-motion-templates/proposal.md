## Why

Prompt Motion exposes many reusable prompts and skill-linked cases, but the packaged pipeline
only names two source-method examples. The user prioritizes maintaining a template library;
brand replacement, project generation and rendering are not requested in this increment.

## What Changes

- Inventory the current visible case metadata with exact source URLs, author, date and page-type
  provenance; distinguish indexed candidates from curated recipe templates.
- Maintain a bounded initial set of useful recipe templates: task fit, replaceable inputs,
  sequencing, motion invariants, gotchas, related existing methods and explicit unrendered status.
- Add read-only offline `film templates` search/detail access and a maintenance path that produces
  reviewable index refresh candidates/diffs without approving recipes or removing old templates.
- Register packaged files/tests and document addition, update, duplicate, removal and review rules.

## Capabilities

### Modified Capabilities

- `design-pipeline`: maintained Prompt Motion recipe templates and case discovery.

## Impact

Prompt Motion guides, supporting catalog/helper, existing film CLI registration, maintenance
script, package/test manifests and focused checks. Reuse existing film methods, choreography,
reference evidence and target/receipt contracts. No new renderer, production generator,
scheduled automation, dependency or acceptance gate. Original prompts/videos are not mirrored;
the recipe summaries are authored adaptations with source attribution. No Multica on this host.
