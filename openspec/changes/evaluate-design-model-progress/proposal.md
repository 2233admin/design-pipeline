# 珐琅徽章的模型与工具对照

## Why

- 第一轮工具版和直接制作版共用简化资产，用户观察到没有明显提升；不能用该实验推断独立创作增益。
- Canvas / CSS 平面遗漏原片的实体层厚、釉面和随视角变化的材质；门禁通过也没有解决画面问题。
- GLSL 修正版补上材质路线，但变更了资产；它能验证实现能力，不能单独证明工具带来的因果提升。
- 历史记录缺少逐版模型、输入、预算与用户意见，无法公平地判断后续迭代。

## What Changes

2026-10-06 用户要求补上 RSI 的实际改进路径及制作中的主人校对，并明确成品只呈现徽章／交互动画，模型、调参及源码属于开发评测入口。此范围复用 visual.review、native next/decide、现有完成证据及失效机制；修复关键视觉任务技术完成即推进和已完成目标无法退回两处接线。反馈回流使用既有 feedback/OpenSpec 修复，外部 adaptation 的独立评估／晋升边界保持原样。默认徽章入口改为成品展示；现有评测台用本项目设计工具整理视觉层级和对照／反馈，不启动新模型，不新增评测案例。

2026-10-06 用户纠正修复目标为视频内容分析／拆解与现有仓库分析。本轮新增打包的
`reference analyze-video` 和 `project inspect` 实际入口：真实视频时间轴、原尺寸有序样帧与
逐对象观察要求，及带文件／行号／摘要的入口、引用和渲染／材质／动画源码证据。复用
原 reference-evidence 的可选 videoAnalysis 绑定、原 aggregate 检查和 artifact.v1；不新增
另一套 gate、receipt、target resolver 或模型默认配置。语义理解和视觉认可仍需实际观察。

### Latest scope: tool dispatch and task decomposition repair

2026-10-06 用户要求先修工具，再由 Grok 4.7 与 Qwen 3.8 Flash Next 制作同一徽章。调用链已复现 quick replicate 跳参考、route 到 typed request 的交接缺失、图形任务漏选运行时仍 ready 三处断点；现有制作指导也缺逐视觉目标的具体输入、检查和返修路径。本轮修复方案见 [工具派发与任务拆解修复计划](tool-dispatch-repair-plan.md)，实施状态与审阅版本见 README。

拟扩展既有工具入口与指导，复用 request.v1、Stage 0 绑定和 reference/scene/task 合同；不新增门禁或收据，不承诺自动视觉部件执行器。徽章仅作为固定评测案例，通用修复不硬编码徽章部件。此前批准的评测底座计划不包含这份工具补丁，历史范围与结果保留。

### Current scope: component evaluation foundation

2026-10-06 用户确认先搭好可观察、可分阶段验收的评测底座，当前案例仍仅为珐琅徽章组件。关键视觉节点由用户验收，其余符合条件的步骤自动推进；模型已有无限 token，后续运行不以累计 token 或旧统一 12 分钟上限淘汰。用量与耗时继续记录，旧实验的原始预算与结果保留。

本轮已确认范围整理为 [组件评测 SRS](component-evaluation-srs.md)，用户认可规格与轻量文档方案，并再次认可[实施计划](component-evaluation-implementation-plan.md)及[改前基线](component-evaluation-baseline.md)。原批准版本见 README。本地底座已实现，接入旧记录、七个顺序小任务、逐次模型身份、公开执行事件、源码快照和版本绑定的人审／反馈；没有启动新制作模型。以下模型追加、导出与路由内容是此前已执行工作的记录，不能当作本轮新派发。

### Add

本 change 的当前范围只包含用户原片的珐琅徽章：保留逐版 PRD、制作流程、真实模型、失败和原片对照，由用户评价几何、珐琅材质与拆合运动。2026-10-06 用户明确停止前端和游戏 VFX，随后授权加入新配置的 Qwen 3.8 Flash：只追加该模型的徽章工具 / 直接配对，不恢复其他任务。

此前执行的 24 次尝试保留为历史，其中徽章 8 次，其他任务 16 次。加入 Qwen 两组后，徽章累计 10 次尝试；页面只展示 MiniMax、Grok、Qwen 的徽章配对，6 个位置、5 份可查看作品。缺失与 Codestral 徽章失败保留，不删除失败后计算工具增益。原始作品不被覆盖。

Qwen 的已配置 selector 为 `futureppo-qwen/qwen3.8-flash-next`。复用现有徽章提示、参考图片、运行库、12 分钟预算和冻结的 V3 工具快照；high 推理、两份独立上下文、关闭回退。实际响应模型仍以事件记录确认。页面按模型配对排列，默认显示模型，旧作品、标签和评分保留。

### Modify

将本地评分入口收窄为单一徽章对照，原片直接可见，保留原来的产物摘要和评分存储；导出只包含徽章。已完成的 VFX 路由和 Three.js lifecycle 修复另列为历史工程结果，不作当前新增评测任务，也不据此声称徽章画质提升。复用现有记录和页面，不增加产品门禁或收据格式。
