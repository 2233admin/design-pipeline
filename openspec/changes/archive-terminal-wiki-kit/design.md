# Design

## Decisions (made without asking)

- **Where it lives**: `examples/archive-terminal-wiki-kit/`. The repository keeps worked cases in `examples/`
  and there is no design-system package catalog under `skill/`; the package uses the `design-system/` layout
  that `design-system check --project-root <dir>` reads, so the example root is a project root.
- **Named by the grammar, never the source**: "archive terminal" (an archive read through a terminal). No file,
  test, commit or PR names the reference site, its game, studio or characters. The demo world (《霜线》
  FROSTLINE, its agents, arms, items and events) is invented. Reference screenshots, the raw measurement dump
  and the owner's private copy stay outside the repository.
- **Numbers, not code**: colours, sizes, durations and curves were read with `getComputedStyle` (light and dark
  through `prefers-color-scheme`, 1440×900 and 390×844) and pixel samples; they were re-entered as our tokens.
  No CSS, JS, icon, image, font or logo from the reference is used; icons are drawn for the kit
  (`build/icons.cjs`, 24-unit line icons) and the mark is an original line drawing.
- **Accessibility over fidelity, recorded**: `ink-muted` one step darker in light (4.11 → 4.92:1 on
  `panel-muted`); `ink-subtle` flattened from 70% alpha; `accent-ink` added because accent-coloured text
  measures under 3:1; the light focus ring is ink (the reference's accent ring is 1.4:1); disabled states keep
  4.5:1 instead of 50% opacity; hero dots lightened so text crossing a dot keeps 4.5:1. Each is in DESIGN.md
  Source Decisions and in the token's usage note.
- **The chamfer and the ring**: `clip-path` cuts would slice an outline, so every focused element drops its
  cut (`.at-page :focus-visible { clip-path: none }`).
- **Checker-readable markup**: dates and chips are separate elements so a text unit has one colour; search
  inputs use `aria-label` rather than a visually hidden label (the browser check measures clipped text); the
  skill table's cells, which scroll horizontally on phones, carry `data-bleed`; the skip link carries
  `data-bleed`; the closed drawer is `visibility: hidden` (also keeps its links out of the tab order).
- **Generated vs hand-written**: templates, `templates/tokens.css` and previews are generated by
  `build/build.cjs` from `build/parts.cjs` so pages and previews share one markup source; `bundle.css`,
  `kit.js`, READMEs, GRAMMAR, DESIGN and MOTION are hand-written. The test fails when generated files drift.
- **Version notice** opens itself once per version on the home page for people, never under automation
  (`navigator.webdriver`), so checks see the page and `?notice=1` forces it.
- **Art**: slots carry size, safe area and task id; seven task sheets with prompts and a `tasks.json`.

## Evidence

- `design-system check`: ready, 22 components, 50 contrast pairs × 2 themes pass, no unused token except the
  `primary` alias. `foundation check --kind all`: ready.
- `template check --browser`, first pass → final. Pages (8 pages × desktop and 390): 759 findings → 0. The first
  390 run used a fixed 844 px canvas, so most of the 759 were content below the fold and the off-canvas drawer;
  the real ones were contrast over hero dots, date + chip read as one mixed-colour unit, disabled text dimmed by
  opacity, visually hidden labels, a scrolling table and the skip link. Dark theme pages (7): 0 at final.
  Compiled previews (23, each with a light and a dark section): 37 → 0 (sr-only label, link buttons inheriting
  ink in dark, a mixed-colour title, a side nav cut by its preview frame).
- Fidelity against a private offline copy of the reference (repository `evaluate-website-clone.cjs`, 4 page pairs
  × 1440 / 768 / 390, content and assets excluded by design): verdict `fidelity-limited`; pixel difference
  0.06–0.29 (pixelmatch 0.15), landmark deltas small for top bar and main column, large where page heads and
  hero layouts differ on purpose. Kept with the owner, not in the repository.
- Keyboard and focus (Playwright, both themes): first 31/47 → final 47/47 (search focus ring under 3:1,
  clipped focus on chamfered links, focus escaping the modal).

## Compatibility

Additive. No schema, rule, gate, receipt or CLI change; nothing under `skill/` changes.
