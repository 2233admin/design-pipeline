# archive-terminal wiki kit: a game-wiki component library and page templates as an example package

## Why

Closes #322. The owner wants a reusable component library and page templates for game reference wikis, in the
visual grammar of a community-maintained game wiki whose interface is styled after its game's in-game terminal
UI ("照着他那个网站我们做一个模板，就是要做一套组件库模板"). The repository has the design-system package
format and checks (`design-system check`, `foundation check --kind all`, `template check --browser`) but no
shipped package that exercises them end to end, and no wiki page templates. Without one, the next wiki brief
re-measures the same grammar and re-learns the same traps (accent used as text, chamfered corners slicing the
focus ring, disabled states dimmed below 4.5:1, sr-only labels and mixed-colour units read by the checker).

## What Changes

- **Example package `examples/archive-terminal-wiki-kit/`** in the existing design-system package layout:
  `design-system/tokens.json` (light and dark, contrast pairs, size, shadow and motion families), `README.md`
  usage rules, 22 components each with guidelines and a live preview, a cover, the shared `bundle.css`;
  `DESIGN.md` (Google format, front matter generated by `design-system design-md-tokens`) and `MOTION.md`.
- **`GRAMMAR.md`**: the measured grammar (colour in both themes, type scale with the bilingual 中文 / ENGLISH
  label pattern, spacing, chamfer, shadows, the strip / grid / dot / bracket / stripe motifs, accent rules,
  motion) and the reasons the reference's own code and assets are not included.
- **Seven page templates** (home, entity detail, list with filters, item detail, event article, recent changes,
  search) plus a gallery, in plain HTML, CSS and vanilla JS (`templates/kit.js`), responsive to 390 px.
- **Art slots and task sheets**: every picture is a sized placeholder (`.at-slot`, `role="img"`, `data-task`)
  with an image-generation task sheet under `art-tasks/`; showcase previews carry no characters.
- **`build/build.cjs`** regenerates templates, `templates/tokens.css` (via `compileTokensCss`) and previews from
  shared markup; `--check` reports stale files.
- **`tests/archive-terminal-wiki-kit.test.cjs`**: package ready, foundations ready, generated files current,
  task sheets match slots, no remote assets, previews carry no pictures, and `template check --browser` on two
  pages where Chrome and the CJK fonts are installed.
- No change to any CLI command, check rule, schema, gate or receipt.

## Capabilities

- `design-pipeline`: the repository ships a design-system package example with wiki page templates.

## Reuse

- `design-system check|compile|design-md-tokens`, `foundation check --kind all`, `template check --browser`,
  `compileTokensCss` and `checkDesignSystemPackage` from `design-system-package-core.cjs`, the motion primitive
  `reveal.trim-line`, and the art task-sheet format already used for generated-art requests.
