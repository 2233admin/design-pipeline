# Expand Motion Recipes to the Full Reference Catalogue

## Why

The user rejected limiting Motion Reference adoption to four examples and approved complete category/item coverage, reusable mechanism recipes with explicit variants, and separate web/game UI/text/film usage guidance. The current four original recipes are useful but do not describe the source catalogue's breadth.

## What Changes

- Enumerate the actual fully merged public source catalogue, reconcile advertised totals with observed unique IDs and category membership, and establish whether text motions are a subset. Do not generate rows to force the advertised 782/228 counts.
- Publish a attributed factual source-item index with complete membership, short names, source links and source-displayed parameters; no copied source code, long descriptive text or assets.
- Map every observed entry to an original mechanism recipe and explicit supported variant. Parameter-only differences may share an implementation; distinct mechanisms require actual implementation branches, not generic fallbacks or name-only mappings.
- Provide runnable offline family/variant studies and concrete adaptation instructions for basic motion/principles/easing, web interactions/state/layout/scroll, game feedback, all text categories and film/scene effects.
- Integrate item-level discovery through the existing catalogue doc/method source model and canonical project ownership. Preserve the four existing working recipes and existing component-only platform filtering.
- Prove full membership, mapping/parameter validity, searchable paths and exercised implementation branches. Continue to record technical evidence separately from owner Visual Acceptance.

## Existing Contracts Reused

Reuse design-system snapshot/catalogue v1, canonical source identity/license/path/hash contracts, project primitives and MOTION.md, opportunity/transition/review guidance, reference.md/motion.md/qa.md, supporting tools, and existing packaging/QA. No second dispatcher, public CLI command group, motion gate, receipt schema, token scale or production animation runtime.

## Impact and Boundaries

New original recipe data/guides/studies and narrow additions to current catalogue, workflow indexes and required resources. The external site supplies observation provenance, not an asserted redistribution licence. Ordinary UI must not be silently converted into film; scene studies do not claim production-render acceptance. Concurrent answer-me-with-html, skill installation/discovery, film and research changes remain untouched.
