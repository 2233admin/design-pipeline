## Verification protocol

The only sanctioned check is `node scripts/qa.cjs`, run directly with no pipe or redirect into the repository (`AGENTS.md`: never bare `node --test`). It has no scoped mode and fails unless `git status` is the same at the end as at the start. Workers therefore do not run it; T5 runs it once on a quiet tree and hands failures back to the owner. One exception, stated so nobody guesses: the owner of T3 may run its own new test file by name, `node --test tests/tool-list.test.cjs`, because `AGENTS.md` forbids only the bare `node --test` and `scripts/qa.cjs` runs the same command with the manifest's files (open question Q12). Any other worker checks its change with a throwaway script outside the repository or with the prototypes; that is smoke evidence, not the gate.

`node scripts/tool-list.cjs --check` never writes, so any worker may run it. `--write` writes only `skill/references/tool-map.md`. The prototypes write only into the OS temp folder.
