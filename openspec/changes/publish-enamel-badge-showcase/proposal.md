# Proposal

## Why

The enamel badge exists only in an ignored local study and cannot be viewed or reused from the project on GitHub. The owner requests this specific sample as an open-source project showcase.

## What Changes

- Publish the current renderer as a self-contained static example and retain its material appearance.
- Add actual rendered previews, source attribution, local run instructions and a GitHub Pages link near the top of the project README.
- Exclude third-party reference footage, extracted reference images, private evidence and unused modules.

## Capabilities

No pipeline contracts or requirements change. This is example and documentation publication; skip_specs is explicit.

## Impact

Only examples/enamel-badge, the root README and third-party notice, and this change record. Reuse existing Three.js r180, native postprocessing, sourced shader adaptations and CC0 daylight HDR. No new runtime dependency, gate or receipt.
