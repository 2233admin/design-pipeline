# Direction

Subject: SeedController node canvas. Benefit: reference material, prompts and moving results remain
connected in a workspace that can be organized with natural-language plans. Existing product videos
establish the result before graphics explain relationships. The film is a concept edit, not a screen
recording or a new generation job.

Primary reference observations are in `../ground-films-in-references-and-sound/reference.md`:
cool gray material, spatially moving footage, changes of shot scale, fine annotations and inserts.
Transfer those traits to city/night/moon imagery already used by SeedController. Avoid importing
the reference's biological/laboratory subject matter or treating continuity as the whole aesthetic.

Runtime: one paused GSAP composition timeline, Canvas 2D compositing of locally decoded video,
and a local stereo score synchronized to the same playhead. DOM playback/mute/volume/seek controls
stay outside the 1600x900 composition. Assets load before the explicit play-with-sound action.
Stage 1 proof uses the first 7.5 seconds, including music and the wide-to-detail video edit.
