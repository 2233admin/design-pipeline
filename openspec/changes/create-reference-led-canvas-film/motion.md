Posture: cinematic. Registered primitives: reveal.trim-line for annotations and connections,
transform.orbit for the limited detail-marker arc. The actual source video supplies subject and
camera motion. Fixed clip windows and one 32-second GSAP timeline drive the composition.

The same moon shot changes from full-frame footage to a canvas node. At 23.75s, the selected
night node expands over the retained canvas before the result montage. The soundtrack shares
the composition clock; muted clip audio cannot overlap the score.

Real-time first-passage and full-film evidence, seeking and narrow-screen observations are
recorded in QA.md. Runtime evidence is not a substitute for creative acceptance.
