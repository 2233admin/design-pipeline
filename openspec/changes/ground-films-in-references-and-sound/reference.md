# SEAM 动态参考拆解

主参考：[SEAM / LibTV](https://www.liblib.tv/detail/8eee3e10b8c3442882ac631511100ce2)。
页面署名 eeriesherin。角色：画面材质、视频镜头与图形叠加的关系；不是画布品牌/UI 的复制目标。

## 已观察到的内容

通过页面“立即观看”进入播放器，视频元数据显示约 62 秒、1920×1080。通过正常播放、
进度条定位和截图观察以下位置。时间为近似采样位置，不是逐帧标定的剪辑边界。

| 位置 | 实际观察 | 对画布宣传片的启发 |
| --- | --- | --- |
| 开场 | 冷灰色实验室、标本瓶，横向移动与浅景深形成空间感 | 用有内部运动和空间层次的真实视频镜头建立质感 |
| 约 10 秒 | 档案式纸张与记录信息的近景 | 文字可以属于镜头和内容，而不只是单独一页标题 |
| 约 17 秒 | 戴手套的手拿起植物样本，环境物件保持完整空间关系 | 产品动作和画面主体本身发生变化；不是把静态素材放大 |
| 约 24 秒 | 背景影像之上出现多个局部画面、方框、编号和细连线 | 将画布节点的语义转成视觉标记，嵌入作品镜头 |
| 约 33 秒 | 有机形态的微距材质，图形框与细线指向局部结构 | 图形用于引导观看；复杂质感来自视频素材本身 |
| 约 38、47 秒 | 花瓣、枝条、架体的前中后景，前景虚化与镜头运动 | 可用不同景别、遮挡和运动方向建立剪辑节奏 |
| 约 56 秒 | 手持另一件标本，与实验室环境呼应 | 以回到主题物件的方式收束视觉主题 |

播放器曾显示未静音状态，但这不证明助手听到了音频。本轮工具未返回可听辨的音频；
曲风、BPM、鼓点位置和音乐来源均未核实，不能描述成已完成听辨的结论。以上也不构成
逐帧完整看完并听完全部 62 秒的声明。

## 已有素材证据

“查看创作过程”进入只读项目，能看到工作流、故事板两个视图，以及多组图片到视频节点。
故事板直接显示已有视频，包括 6 秒 1280×720、3 秒 1920×1080、4 秒 1280×720 的条目。
这是可供选择和剪辑的运动素材，不需要先用一张风景图代替所有镜头。只读检查未点击
“复制项目”，未下载、搬用或修改该项目资产。

用户表示已有完成的视频。本轮已询问该链接只用于风格对齐还是也复用现成素材；具体素材
使用范围和本机路径仍待确定。参考访问不自动等于可以把其中所有素材用于新片。

## 与上一版的关键差距

上一版让图形连续移动，但主素材始终是一张静态风景图。这个参考的画面主体具有运动、
景深、材质变化和镜头语言；图形叠加支持影像。方向修正应包含素材选择、剪辑与声音，
而不是继续增加卡片动画、再给最终画面补一首背景音乐。

## 画布项目的改编方向（建议，尚未制作或获得认可）

先用现成作品镜头建立吸引力；在动态画面中引入局部标记和画布连接关系；再让观众看见
多个镜头如何在画布上被组织、比较、编排，最后回到成片结果与 SeedController 品牌。

保留参考中的冷静材质、景别变化、局部放大与细图形；不照搬实验室/标本题材。
ASCII 作为短暂的结构揭示和文字材质，是否保留取决于主参考和实际素材的适配性。
音乐先定情绪发展与可用来源，再把切点、揭示、停顿和品牌收束写进同一份声画分镜。
