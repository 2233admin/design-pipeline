# Direction and implementation

Deliver one 40-second 16:9 HTML film with play/pause, seek, chapter navigation, replay, and
fullscreen. Preserve the previous Motion Studies page on port 4173; this film uses 4174.
Signature: an ASCII point-cloud seed becomes an expansive node canvas, then a finished landscape.
Use monochrome ASCII for the structural scenes and cinematic color for material/output scenes,
with restrained silver, ample empty space, and short Chinese headlines. This is
original product art, with no Apple trademarks, copied footage, or implied endorsement.

The selected iart launch-video and kinetic-typography references provide narrative and typography
guidance. For this silent HTML capability test, use visual timing instead of the reference's
music-led workflow. One original imagegen landscape provides demonstration imagery. No user
media, voiceover, sound, or video export is required.

HyperFrames composition contract: direct body root, explicit 1600x900 / 40s metadata, and exactly
one paused GSAP timeline registered in window.__timelines. GSAP 3.13.0 is vendored from npm with
its license. Local preview drives the same timeline. The ASCII generator depends solely on
timeline time; no random or wall-clock input. HyperFrames CLI/render validation remains separate.
