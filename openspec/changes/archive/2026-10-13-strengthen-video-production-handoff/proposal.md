# Proposal

internalize-art-motion-naming; paths describe the layout at the time.

## Why

The Ado reference trial marked eleven coarse observations ready although important late transitions lacked dense samples and no confirmed shots, object properties or production inputs were bound to dispatched work. The user explicitly requested fixing these defects before making a whole-film structural sample with separately rebuilt character artwork.

## What Changes

- Select motion candidates by local prominence across the source, retaining source-cadence context within the existing frame budget and reporting omitted candidates.
- Extend the existing video report with confirmed shots and applicable target properties; require this inventory for production readiness while keeping historical reports readable.
- Extend existing visual tasks with an optional source-observation binding; require that binding when their references include a video report, and validate its target, property, shot and frame evidence at dispatch and completion.
- Include declared guides and bound source evidence in existing input hashes so changed methods or observations invalidate downstream evidence.
- Repair stale Art Motion reference method and packaging paths exposed by integration QA after the preserved upstream source moved to its full engine topology; retain pinned source bytes and matching license copies.
- Use the repaired skill to make one whole-film structural sample, keeping rebuilt assets and unverified visual similarity explicit.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `design-pipeline`: video-reference production readiness and evidence-bound visual task dispatch.

## Impact

Changes are confined to the existing reference-video checker, visual plan validator, workflow callers, their guides and registered tests. The existing v1 gate, report carrier, design plan, artifact receipts and invalidation chain remain authoritative. No new dependencies, evaluation workbench or model runs are required. Structural readiness does not establish semantic or visual acceptance.
