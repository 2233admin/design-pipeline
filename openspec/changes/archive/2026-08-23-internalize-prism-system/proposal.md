# Proposal: internalize Prism System's design intelligence

## Why

The pipeline already owns design tokens, component catalogs, adapters, and verification. It lacked
Prism System's coherent Design DNA, five-route intake, corpus-distillation, token-governance, and
handoff recipes as an offline, revision-pinned capability.

## What

- Pin and preserve the complete MIT-licensed Prism design-skill layer: 107 skills and both
  registries.
- Add deterministic integrity checking, local search, and the five-route request classifier.
- Adopt Prism's reusable rules inside the existing pipeline stages without adding a second token
  source, component library, controller, or build chain.
- Package provenance, source bytes, attribution, CLI access, and regression coverage.

## Boundary

The bundled snapshot is inert reference material. It excludes components, fonts, sample brand
data, screenshots, generated outputs, Storybook, and build dependencies. Upstream autonomy labels
do not override workspace authorization or project contracts.
