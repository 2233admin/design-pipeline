## Why

The pipeline has interface review and animation guidance but no complete, reachable built-in
good-css library. Installing an ambient skill would leave packaged users without the practices,
credits and live specimens. Copying only its prompt would lose conditional rules and source evidence.

## What Changes

- Preserve the entire reviewed Git tree, including all practice/reference files, fixtures,
  assets, generator/checker and deployment source, with MIT and font-license attribution.
- Add one maintained good-css guide with a complete practice-to-project coverage map and
  browser, accessibility, token, framework and deterministic-film adaptations.
- Route CSS writing/review through that guide from existing skill, stage, web, tool and QA entries.
- Provide a dependency-free local study builder for all specimens using the existing source
  fixtures. Keep build/deploy/install metadata inert; do not import the upstream dependency graph.
- Register source integrity, practice parity, offline-study and isolated-package checks.

## Capabilities

### Modified Capabilities

- `design-pipeline`: built-in frontend CSS implementation guidance and packaged study tools.

## Impact

Reuse `scripts/git-tree-snapshot.cjs`, `package-resources.json`, `test-manifest.json`, the companion
source metadata/audit and existing package/browser checks. No new gate, receipt, target resolver,
policy digest, required companion or npm dependency. Preserve all unrelated working-tree edits.
The user authorized implementation; no remote publication or global skill installation is required.
