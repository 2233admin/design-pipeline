## Posture

Static. This change adds JSON contracts, command-line operations, and documentation. It does not add
an animated product surface or select a motion runtime.

## Authority

Project `MOTION.md` remains the reusable motion authority. Provider docs, templates, token data, and
benchmark candidates may supply attributed evidence but cannot replace or rewrite the project's
motion vocabulary, reduced-motion behavior, timing, choreography, or runtime decisions.

## Provider Treatment

- Motion-related provider tokens are projected only when representable in the existing token
  contract.
- Unresolved duration, easing, transition, or semantic-role mappings are recorded as projection
  loss.
- Runtime adoption still requires an explicit `design-system decide` result and does not follow
  from the presence of provider motion examples.
- Provider executable examples and `.doc.mjs` modules are not run by the kernel.

## Reduced Motion

Every repository workflow remains immediate text and file state. Benchmark candidates must be
evaluated under the same reduced-motion requirements and representative delivery conditions.
