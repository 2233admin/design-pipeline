# Motion as the page

Audience: the project owner evaluating visible animation quality. Single job: open the page and
see several clear, authored animation compositions. Signature: a blue orbital sculpture whose
satellites share an axis with editorial typography and ruled labels.

Design: warm paper, ultramarine, charcoal, and a small lime accent; asymmetric title and stage;
large numbered studies separated by rules rather than repeated cards. Desktop uses paired
columns, mobile keeps the same reading order in a single column. No external fonts or assets.

Keep all substantive copy visible without JavaScript. CSS owns looping motion; IntersectionObserver
adds reveal classes; pointer transforms only apply to the poster's decorative interior. A pause
button and system reduced-motion support freeze effects at readable positions.
