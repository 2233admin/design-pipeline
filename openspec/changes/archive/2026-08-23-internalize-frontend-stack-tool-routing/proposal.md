# Proposal

Add one declarative frontend-stack registry and one compact MengTo skill index. Reuse the existing
design-system CLI namespace and catalog normalization instead of creating a parallel command tree.
Restore the missing capability decomposition and component-route kernels, then bind their outputs to
`design-system decide`.

External repositories are routed as attributed candidates. The built-in website-cloning and
feedback modules remain the executable paths until installation, credential, or repository
authority is explicit.
