## Why

Taste-Skill is named in the pipeline but depends on ambient skill installations. Five of its thirteen skills, including the default v2, are absent on this host and none of the suite travels with the package. The user requests complete internalization into the tool.

## What Changes

- Preserve the complete reviewed MIT source tree at `b482f7a970abb98c4108d4a9f761e458c64cefc8`, including all thirteen skills, research, Stitch's DESIGN.md example and supporting assets, using the existing Git snapshot helper.
- Add a maintained built-in guide that selects the appropriate skill by deliverable, maps every skill to existing pipeline artifacts and verification, and resolves upstream/project conflicts explicitly.
- Connect the existing skill entry, frontend/design/asset/brand routes and existing companion profile to packaged local sources. An empty external skill root must not remove Taste coverage.
- Register all required packaged resources and verify complete source identities, rejection paths, reachable guide links and isolated installation.
