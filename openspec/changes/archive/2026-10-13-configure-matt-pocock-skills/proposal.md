## Why

The installed Matt Pocock engineering skills expect repository guidance for the issue tracker, triage roles and domain documents. This repository lacks those consumer files, so defaults could select a historical tracker or duplicate the existing glossary.

## What Changes

- Add the three `docs/agents/` consumer guides and an `AGENTS.md` entry following the workspace kit.
- Preserve Multica as execution authority, existing triage roles, `docs/glossary.md` and OpenSpec decisions.
- Install the latest upstream skills in the canonical host skill root with backups. Installations and verification receipts remain outside tracked product source.

## Capabilities

### New Capabilities
- `repository-agent-setup`: repository-specific consumer configuration for installed engineering skills.

### Modified Capabilities
None.

## Impact

Repository agent guidance only. No packaged skill runtime, gates, schemas or dependencies change. The workspace rule selecting AGENTS.md overrides the upstream setup preference for CLAUDE.md. Existing unrelated edits remain intact.
