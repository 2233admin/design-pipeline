# Broaden scope to agent art literacy

The project was framed as a design-first workflow for frontend/UI work. The film work showed a
wider and more valuable target: raising any agent's art and design literacy — composition, art
direction, motion, animation and promotional film — by carrying creative judgment in code, so
that models other than the strongest one produce work that meets the user's need.

Update the project contract, package description and README to state that purpose and the
three-layer capability model (gates, templates, evals). Frontend/UI remains the first surface;
no existing behavior changes.
