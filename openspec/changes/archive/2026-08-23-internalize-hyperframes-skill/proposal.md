# Internalize HyperFrames skill contract

Record the official HeyGen HyperFrames workflow as a governed, project-owned video route. Keep the
portable entry/core/CLI rules in the package while leaving the upstream workflow tree and runtime
installation optional.

## Why

The existing HyperFrames registry entry was keyed to the always-present `design-workflow`
capability, so ordinary UI requests could route to it. The official skill also provides a stronger
HTML, deterministic-seeking, and check-before-render contract than the generic motion guidance.

## Scope

- Correct the route to video-specific capabilities and explicit video-deliverable keywords.
- Bundle a concise reference for entry routing, composition determinism, and the production gate.
- Record upstream revision, Apache-2.0 provenance, optional companion skills, and tests.

## Out of scope

- Bundling HyperFrames, Chrome, FFmpeg, or the full upstream skill tree.
- Installing or upgrading a target project's CLI automatically.
