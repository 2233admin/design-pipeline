# Fincept Terminal v4.5.0：能力实测清单（供 KATANAview 布局/工作区重设计参考）

> 本文记录的是**能力、交互和流程**，不是界面像素规格。Fincept 的 LICENSE 里有 Trade Dress 条款，禁止复刻实质相似的屏幕布局、组件词汇和视觉识别，所以这里不描述配色和外观，也不给出可照抄的尺寸。
> 所有结论都来自对运行中应用的操作（computer-use：AX 树 + 窗口级截图/点击/拖拽/按键），没有阅读源码。

## 环境

| 项 | 值 |
| --- | --- |
| 产品版本 | Fincept Terminal **v4.5.0**（状态栏、Help 中显示 `v4.5.0`），开源版，套餐为 FREE |
| 安装位置 | `C:\Program Files\FinceptTerminal` |
| 显示器 | 1 台 3840×2160，Windows 缩放 **175%**（scale 1.75） |
| 窗口尺寸 | 起始为非最大化 **3459×1921 物理像素**，位置 (191,103)，约合 1977×1098 逻辑像素。测试中途窗口变成最大化（3840×2076），原因未查明，见「其他观察」。重启后仍是最大化；收尾时已点「还原」，回到 3459×1921 @ (191,104)。 |
| 分析库 | 首次启动的「安装分析库」一步被**跳过**，所以依赖它的功能记为「缺分析库」。本次覆盖的布局/工作区能力都没有碰到这一限制。 |
| 登录状态 | 用户本人已登录（账号信息不记录）。截图中的用户名、邮箱、积分和模拟余额都已打码。 |
| 输入方式 | 窗口级后台输入。Qt 的 OLE 拖放（把代码拖进另一个面板）和带 Ctrl 的组合键在后台输入下不生效，相关行注明「输入注入限制」，不算产品缺失。 |

**最值得 KATANAview 学习的：** ① 首次安装有分阶段的进度，并显示耗时和速率，可选的重活允许「跳过并继续」；② 语言切换始终放在右上角；③ 默认工作区开箱就有数据，组件显示骨架屏和逐项加载计数。
**反面教材：** 每次启动都弹推销；登录后先进定价页；重启后的 PIN 锁没有提前说明。
