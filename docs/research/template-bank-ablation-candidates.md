# 模板库消融候选：强调色预算、标题不压人物、公共左对齐线

日期：2026-11-04　关联：#260（分层消融评测）、#261（模板库）

调研（[明日方舟 / 终末地版式调研](arknights-endfield-template-study.md) 第 6 节、
[ignoredone's space 调研](ignoredone-arknights-design.md) 第 4 节）列了十几条可开关的规则。
这里登记其中建议先做的三条：它们的信号能直接从渲染出的 SVG 算出来，不需要人评；在官方样本里一致性也最高。
三条都已经是 `template check` 的量测项，所以消融时“开 / 关”就是同一份模板在检查里打开或去掉这一项，
信号由 `template check <out.svg> --json` 的 `measured` 与 `findings` 给出。

每条规则只登记，不预设结论：先写判定规则，再按 #260 的方法（固定简报、完整 / 去掉一层 / 裸模型、每组 N≥5、盲评另一模型）跑。

## R-A 强调色预算

| 项 | 内容 |
| --- | --- |
| 开 | 强调色（模板 `accent.roles` 的颜色，以及与之同色的任何填充）面积 ≤ `accent_max_share`；荧光色只给可操作元素或标语条 |
| 关 | 不限面积 |
| 信号 | `summary.accentShare`（渲染面积 / 画布）；`accent-budget` 发现及其最大贡献元素 |
| 官方基线 | 明日方舟 KV 强彩像素（C*>50）中位 0.9%，时装 KV 2.3%；终末地 KV_OPERATOR 11.6%，荧光黄中位 2.4%；终末地 UI 24 张里 14 张有荧光黄，只在主按钮 / 标签 / 当前项 |
| 模板默认 | 时装 KV 3%，新角色 KV 5%，终末地叙事 KV 3%，终末地名牌 KV 12%，横幅 8%，UI 与视频封面 2%，档案卡 2% |
| 判定（预写） | 开启组的 `accentShare` 中位数低于关闭组，且盲评“专业 / 克制”胜率不低于关闭组；否则这条规则不进默认 |
| 测不准 | 像素基线用 h_ab 92–115° 判荧光黄，会把黄绿色插画算进去；模板里的量测按颜色等值与角色统计，文字面积按外框 45% 估墨量 |

## R-B 标题不压人物

| 项 | 内容 |
| --- | --- |
| 开 | 标题槽（`title`）与人物区（模板声明的 `figure` 区）横向重叠 ≤ 30% 标题宽（两者纵向相交时） |
| 关 | 标题位置随意 |
| 信号 | `figure-zone` 发现的 `overlapShare`；渲染后标题与人物区的重叠比 |
| 官方基线 | 时装 KV 0/13、新角色 KV 0/6 重叠 >30%；视频封面 5/8 重叠，但都有渐变托底（所以 `cover.pv-lowerthird` 不声明人物区，改由对比度检查兜底） |
| 判定（预写） | 开启组标题可读字形比例（对比度达标的采样点占比）不低于关闭组，且盲评“层次清楚”胜率高于关闭组 |
| 测不准 | 人物区是模板里的槽位框，不是抠像轮廓；真实人物在框里的位置不同，重叠比会偏保守 |

## R-C 公共左对齐线

| 项 | 内容 |
| --- | --- |
| 开 | 模板列出的元素（logo、标题、元信息、标语条等）左缘落在同一条线上，容差 0.5%W；`ui.ef-activity-panel` 另有右对齐线 |
| 关 | 各自摆放 |
| 信号 | `align-line` 发现的 `offsetPx`；各元素左缘 x 的极差 |
| 官方基线 | EF060 的 logo / 栏目 / 标题括号 / 标语条四者同在 0.047W；明日方舟左对齐标题左缘中位 0.05W（p25 0.03） |
| 判定（预写） | 开启组左缘极差中位数 ≤ 0.5%W，且盲评“整齐 / 有秩序”胜率高于关闭组 |
| 测不准 | 拉丁展示字按墨迹左缘对齐（光学对齐），中文 `<text>` 按字身框左缘量；两者的视觉左缘可能差 1–2 px |

## 先不做的

单一主题色相（只对时装 / 系列类成立，要按类别分开报）、中性底、边距节奏、视频封面下三分之一、双比例安全区（`cover.pv-lowerthird` 已经量 16:9 裁切）、
竖排汉字正立、自绘拉丁字、装饰层：见上面两份调研，等这三条跑完再排。
