## 1. 方法

1. **索引**：`/wp-content/plugins/ignoredone-oss-api/oss_data_cache.json` 列出全部 104 组、3062 张图（明日方舟 96 组 2358 张，2019–2026；终末地 8 组 704 张，2026）。画廊**没有分类字段**，只按日期分组。尺寸用 OSS 的 `?x-oss-process=image/info` 逐张读出（3062/3062 成功）。
2. **抽样**：按“游戏 × 画幅类别”分层（每类配额，组间轮转），得到 95 张；因为随机样本里终末地 KV 太少（终末地 16:10 和 21:9 几乎全是游戏界面截图），又从 1920×1080 / 3840×2160 / 2305×1297 等 KV 常见尺寸里补抽 24 张。共 **119 张**（明日方舟 61，终末地 58）。下载的是 OSS 缩放版（长边 1600，长图宽 720），一张动图 webp 取第一帧。
3. **目测**：做了 20 张带编号的拼版（contact sheet）逐张看完 119 张，给每张定类别；对 63 张有版式意义的图（KV、封面、横幅、档案卡、专辑方图）标了标题框、人物横向范围、logo 角位、标题横/竖排。其中 10 张按原尺寸细看并量了边距（EF060、EF059、EF053、EF084、EF072、AK038、AK003 等）。
4. **测量**（`scripts/measure.py`，Pillow + numpy + scikit-image + scikit-learn，长边缩到 480 px）：
   - Lab 空间 k-means（k=6）主色与各簇占比；L* / C* 分位数；中性像素（C*<10）、强彩像素（C*>50）、荧光黄（L*>75、C*>60、h_ab 92–115°）、金黄（h 70–92）、红（h 15–45）、青（h 190–240）像素占比；彩色像素的色相圆标准差。
   - Sobel 边缘能量 3×3 分布、横纵质心、左 40% 占比、8×8 安静格占比、长直线（行/列二值边缘覆盖 ≥45%）、四角活跃度、左右镜像相似度；自动去除视频黑边（letterbox）。
   - `scripts/aggregate.py` 按“游戏 × 类别”汇总中位数和 p25–p75，结果在 `data/aggregate.json`。
5. **模板**：`templates/build.py` 用测量出的比例生成 9 个 SVG（参数写在 `<metadata id="template-params">` 里，改参数重跑即可）；拉丁展示字用 `lettering/` 里我们自己用代码画的字形，中文用开源字体。

## 3. 发现

### 3.1 两个游戏的共同点
- **底色是中性的**：KV 最大色簇的彩度 C* 中位数，明日方舟 2.4（29 张），终末地 1.45（16 张）。中性像素（C*<10）占 61–68%。颜色集中在人物和少量标记上。
- **边距稳定在 3–5% 宽度**：左对齐标题的左缘中位 0.05W（明日方舟 27 张，p25 0.03）；EF060 的 logo、栏目、标题、标语四者共用 x=0.047W；AK038 档案卡外框内缩 0.042W。
- **logo 永远占一个角**：明日方舟 KV 左上 17/29、右上 6/29；终末地 KV 右上 8/16、左上 6/16。版权行在右下或左下。

### 3.2 明日方舟
- **时装 KV（13）**：标题在左 13/13，标题与人物横向重叠 >30% 为 0/13；标题中心 y 0.50H，人物中心 x 0.55、宽 0.40W；最大色簇 L* 中位 89.7（8/13 是浅底）；彩色像素色相圆标准差中位 **14°**，即一张图一个主题色相；强彩像素中位 2.3%。常伴 THEME / KEYWORDS 两行英文小字（左下）。
- **新角色 KV（6）**：名字在左 6/6、在下半幅 5/6，名字区面积只有 4.2%（时装 KV 的一半）；右下是等级与配音署名；背后一条横贯全宽的大字水印带（AK003：y 0.53–0.66H）。
- **视频封面（8）**：标题居中 6/8，标题中心 y 中位 **0.72H**（p25–p75 0.71–0.725），面积 16%；5/8 标题压在人物上 → 都靠深色渐变或标签条保证可读。
- **档案竖图（6）**：上三分之一身份信息、中间立绘、分隔线（约 0.71H）以下技能说明；中性像素 92%，唯一的彩色是红色系技能图标。
- **横幅（4）**：彩度最高的一类（C* 中位 12.7），日期数字是最大的拉丁字形，活动名用实色块托底。

### 3.3 终末地
- **荧光黄是签名色**：出现荧光黄（≥0.2% 像素）的图，终末地 25/58，明日方舟 6/61；只看 KV，终末地 7/16、明日方舟 4/29。终末地 UI 截图 14/24 有荧光黄，而且只在主按钮、标签、当前项和标语条上。
- **新角色 KV（4）**：强彩像素中位 11.6%（明日方舟同类 1.8%），荧光黄 2.4%；常见“白底 + 荧光碎片 + 右下白色名牌”。
- **活动/版本 KV（12）**：最大色簇 L* 中位 96（白底为主，11/16 浅底），标题居中 8/12，标题压人物 7/12；版本主视觉常用竖排汉字大标题（EF053、EF058）。
- **文字语法**：页面/栏目名前缀 `//`；标题用方括号 `[ ]`；极小号宽字距英文标语（EF060 约 +900/1000 em）；十字准星微标、三色短条、条码短条等“工业秩序”小装饰。
- **UI（24）**：左导航 x 0.06–0.20W，当前项色块出血到左缘；标题右对齐到 0.94W；内容面板 0.545–0.94W；深色场景（最大色簇 L* 中位 15）。

### 3.4 没用上的信号
自动边缘统计对版式区分度很低：边缘能量横向质心在所有类别都是 0.48–0.53，左 40% 占比 0.34–0.42——人物的细节压过了文字。所以标题/人物位置用的是目测标注，边缘统计只作背景数据保留在 `data/measures.csv`。

## 5. 自绘拉丁字（`lettering/`）

**为什么**：官方图里的拉丁展示字我们没有也不能分发，用随便一个系统字体替代会直接丢掉风格。

**从样本认出的三类拉丁字**（`data/sheets/latin_crops.jpg` 是对照裁片，只在本机）：

| 用途 | 样本 | 字形特征 | 开源近似（许可证已在 google/fonts 的 METADATA.pb 核对） |
|---|---|---|---|
| 名字、OPERATOR 标签、活动大字、UI 数字 | AK003 ASCALON、EF059 OPERATOR+、EF055 CONTINGENCY、EF078 04–07 | 几何无衬线粗体，圆形 O，紧字距 | Montserrat（OFL）、Outfit（OFL）、Urbanist（OFL）、Archivo Black（OFL） |
| 终末地战术/PV 标题 | XEF09 CURRENT POSITON | 窄、方角、斜切角、带模版断口 | **没有足够接近的**；最近：Big Shoulders Stencil Display（OFL）、Saira Stencil One（OFL）、Chakra Petch（OFL，斜切角）、Oxanium（OFL）、Teko（OFL） |
| 背景水印大名字 | EF052 LAEVATAIN | 高窄无衬线 | Bebas Neue（OFL）、Oswald（OFL）、Big Shoulders Display（OFL） |
| 宽字距小标语 | EF060 OVER THE FRONTIER… | 几何无衬线 + 极宽字距 | Michroma（OFL）、Montserrat（OFL） |
| 明日方舟时装 KV 的衬线标题 | EPOQUE、FROSTED、FIRELIGHT | 高对比衬线 / 罗马碑体 | Cinzel（OFL）、Playfair Display（OFL）、Bodoni Moda（OFL） |

具体是哪款商业字体我们没有核实，表里只写“像什么”。

**自绘字形**：第二类没有足够接近的开源字，所以用代码画了一套：
- `lettering/lettering.py`：A–Z、0–9 和 `/ \ - _ + . : [ ] < > | # % ! ? '` 共 53 个字形。每个字形是单位方框里的笔画骨架，渲染时按参数变成填充轮廓（斜接拼角，锐角处平切），输出纯 `<path>`，不依赖任何字体。
- 参数：`stroke`（笔画粗/字高）、`width`（字宽比，0.44 为窄体）、`chamfer`（切角大小）、`chamfer_mode`（all / diag 只切左上右下 / none）、`stencil`（模版断口宽，0 关闭；断口位置在每个字形的 `cut` 里定义）、`tracking`（千分之一 em）、`slant`。
- 排字：按字宽算步进（advance）+ 字距 + 少量字偶表（LT、TA、`//` 等），`set_text()` 返回 `<g>` 和实际总宽，模板用这个宽度检查是否超出槽位。
- 命令：`python3 -I lettering.py specimen out.svg`（样张）、`python3 -I lettering.py set "TEXT" out.svg --height 120 --width 0.46 --stencil 0.06`、`python3 -I lettering.py json glyphs.json`（字形集，cap 高 1000 单位，附参数和字偶表）。仓库里已附 `specimen.svg`、`title_sample.svg`、`glyphs.json`。
- 模板里的拉丁标题槽（时装标题、角色英文名、`// OPERATOR +`、方括号、标语、日期数字、UI 进度数字）全部用它生成。

**中文**：不画。标题用思源宋体 / Noto Serif CJK SC 的 Heavy（明日方舟时装与 PV 标题、竖排标题是宋体气质），名牌、栏目、正文用思源黑体 / Noto Sans CJK SC（标题 Heavy/Bold，正文 Regular/Medium）。两者都是 OFL。

## 6. 给 #260 的消融候选

每条都写成可开关的规则 + 可测信号；数字是本次测得的“官方图”基线。

| 层 / 规则 | on | off | 可测信号（基线） |
|---|---|---|---|
| 单一主题色相 | 彩色像素色相圆标准差 ≤25° | 不限制 | `hue_cstd`；明日方舟时装 KV 中位 14° |
| 强调色预算 | 强彩像素（C*>50）≤3%，荧光色只用在可操作元素/标语条 | 不限制 | `vivid_share`（明日方舟 KV 中位 0.9%）、`flyellow_share` 与其位置 |
| 中性底 | 最大色簇 C* ≤3 | 不限制 | 最大簇 C*（明日方舟 KV 2.4，终末地 1.45） |
| 标题不压人物 | 标题框与人物横向重叠 ≤30% | 随意 | 版式框重叠比（时装 0/13，新角色 0/6） |
| 公共左对齐线 | logo / 标题 / 元信息左缘差 ≤0.5%W | 各自摆放 | 各文字框 x0 的极差 |
| 边距节奏 | 文字框到画布边 ≥3.5%W / 4.5%H | 不检查 | 最小边距 |
| 视频封面下三分之一 | 标题中心 y∈[0.70,0.75]H，下方渐变保证对比度 ≥4.5 | 标题位置随意、无渐变 | 标题中心 y、WCAG 对比度 |
| 双比例安全区 | 主信息落在 16:10 ∩ 16:9 交集 | 只按一种比例 | 裁切后槽位是否完整 |
| 竖排汉字正立 | 竖排用 `writing-mode`，字不旋转 | 整行旋转 90° | SVG 里是否出现对汉字的 rotate |
| 自绘拉丁字 | 展示字用 `lettering` | 系统默认字体 | 渲染结果里的 font-family 回退；视觉 A/B |
| 装饰层 | 水印大字、准星微标、三色短条开启 | 关闭 | 层存在与否；人评“工业感/层次” |

最值得先做的三条：**强调色预算**、**标题不压人物**、**公共左对齐线**——信号可以直接从 SVG 槽位和像素算出来，不需要人评，而且在样本里一致性最高。

## 7. 局限

- **抽样偏差**：画廊本身就是转存者的挑选；终末地只有 2026 年 8 组，16:10 和 21:9 全是 UI 截图（很多带 B 站水印和录屏黑边），KV 样本只有 16 张；明日方舟新角色 KV 6 张、横幅 4 张，样本小，结论只能当方向。
- **类别是目测定的**，画廊无分类字段；版式框是在拼版缩略图上估的（误差约 ±5% 画布），只有 10 张按原尺寸细量；单人标注，没有交叉校验。
- **启发式检测误差**：边缘统计被人物细节主导，不能区分文字；长直线检测在长图里会把文字行当成线；荧光黄阈值（h 92–115°）也会算进黄绿色的插画内容；k-means k=6 在缩略图上做，小面积强调色可能并入相邻簇；OSS 缩放后又 JPEG 重压缩。
- **字体识别**只给“像什么”，没有核实官方实际用的字体；自绘字形是我们的风格近似，不是复刻。
- 模板的比例来自少量样本的中位数，套用到别的题材前要用 #260 的消融再验证。
