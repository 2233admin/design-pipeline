## 0. 结论先行

1. **最值钱的不是“明日方舟风格装饰”，而是两套可以写成规则的东西**：
   - 《封面设计排雷手册》（2025-10-02）：字体、字距、行距、阅读顺序、平台裁切、阴影、配色，全部有具体数值或可判定条件，**可以直接做成门禁和消融开关**。
   - 《JUMP [OVER]. 后日谈》（2025-03-31）：作者讲自己一组海报怎么排，核心是一套**抽象排版语法**（圆=图标、矩形=文本块，四种变换算子）和几条**节奏/取舍原则**（负空间、信息密度、侵入比例、边缘压迫、三角构图、面积换线条）。这是“品味与韵律”那部分的主要来源。
2. **模板候选很清楚**：攻略视频封面（16:10 / 16:9 双版）、直播间套件（主画面 + 聊天栏 + 待机页 + 弹幕 CSS，CSS 自带变量化）、3:4 问答教程卡（排雷手册那一套）、终末地工业风教程卡、灰阶角色卡（站上已有现成的参数化生成器）。

## 2. 逐篇：教什么、具体规格、是否有可编辑模板

### 2.1 封面设计排雷手册（2025-10-02，17 张 1080×1440 图）

**卡片本身的样式**（也是模板候选 T3）：3:4 竖卡；外框芥末黄（取样约 #DFBD42），内底奶油色（约 #F3EEDB），字色深棕（约 #5E4B3F）；四角“螺丝钉”圆点；顶部 `✦Q1 ⊕ 标题` 胶囊，下方 `A1` 标签 + 黄色胶囊副标题；大号引号做装饰；虚线圆角框装示例；✓/✗ 圆标判对错；底部小字 `ignoredone's tutorial`。作者自己声明这套配色的色相是 H49 / H47 / H21。

**Q1 字体**
- 不要用 Adobe 黑体（PS 默认字体，非免费商用，版权麻烦）。替代：HarmonyOS Sans、MiSans、思源黑体、思源宋体。
- 字距调整（Kerning）选“视觉”而不是“度量标准”：按字形外轮廓自动调，比统一收紧字距好；英文更明显，中文也可用。

**Q2 行距与字距**
- 行与行之间的空隙不能小于字与字之间的空隙，否则文本拥挤。
- 多行同字重文本：行间空隙取字间空隙的 1.5–2 倍（原文“行间距要在字间距的 1.5 倍–2 倍之间”）。
- 原理：人会把靠得近的东西看成一组（接近律）。反过来，可以故意把字距拉得很开（疏排）或换字体来突出某条信息。
- 字距（PS tracking，千分之一 em）随字体而定：思源黑体/鸿蒙黑体 做紧凑标题 −100，做宽松标题 −50；**任何正文都只用 0**。

**Q3 阅读顺序**
- 只有两种阅读习惯：①从左到右 + 从上到下；②从上到下 + 从右到左。
- 汉字没有西文那种“把字旋转 90° 的竖排”：竖排汉字每个字保持正立，不能整行转 90°。
- 文字被人物分隔成两半时（2×2 字围着人像），排法必须让读序仍然成立：示例中“这是 / 封面”左右分列是错，“封面 / 这是”按从右到左的竖排读法是对（四个示例里两错两对）。

**Q4 平台裁切（B 站）**
- B 站封面两种比例并行，要做两版、上传时都设置：16:9（1920×1080）和作者标为“4:3”的 2560×1600。
  - **审核意见**：2560×1600 实际是 16:10，不是 4:3；作者作品库里的封面也都是 1024×640（16:10）。做模板时以像素尺寸为准，比例名称要再核实 B 站当前规格。
- 裁切痛感表（从轻到重）：FINE＝原图不足 4:3 由 AI 补到 4:3；A BIT＝4:3 裁成 16:9（上下切）；PAIN＝16:9 裁成 4:3（左右切）；PANIC＝16:9 裁 4:3 且不规则；REALLY PAINFUL＝先 4:3 裁 16:9 再裁回 4:3。结论：**关键信息必须落在两种比例的交集安全区里**。

**Q5 效果（外发光/投影）**
- 新手三错：不会调阴影/外发光的不透明度；阴影选了脏颜色；不会换角度和混合模式。
- 外发光与外阴影之间，更推荐外阴影。
- 常见阴影面板（正片叠底、不透明度 100%、角度 90°、距离 0、扩展 0、大小 0）不管图层什么情况都要：①关掉“使用全局光”；②尽量不改阴影颜色；③降低不透明度和大小。
- 全局光让整个工程所有阴影同向，但实际引入的多是点光源，应按各自光源方向调。
- 阴影颜色：保持黑色是最简单的隔离方式；要选色就别和字色冲突，降饱和避免色相冲突。
- 阴影大小：做加法——先把不透明度和大小拉到最小，再慢慢调大，直到图层和背景刚好分得开（“只在图层周围很小一圈”）。

**Q6 配色**
- 尽量避免高饱和的对比色：观感不统一、画面颜色乱（示例：同为互补/对比关系，低饱和版本舒服，高饱和版本刺眼）。
- 前后景：背景用低饱和颜色，明度随意；让有颜色的部分出现在人物和字标上，前后景关系更紧。
- 色相：用 HSL 选色时，除非刻意形成对比，组合中颜色的色相值相差不要超过 120。正例 H49/H47/H21；反例 H126/H22/H222。

模板：无可编辑文件；规则本身可参数化。

### 2.2 JUMP [OVER]. 后日谈（2025-03-31，5 张长图 + 网盘下载）

作者复盘自己的 8 张系列海报（JUMP[OVER].001–008）。整套靠加法组成：“人物 + 摄像头 + 规则排版 + 明快用色 + 几何形状”。配色（取样近似）：底 #F0F0F0 / 白 / 纯黑，荧光黄约 #E4E40C，浅黄高亮块约 #F0F084，钴蓝约 #0C24E4，其余是灰阶。

**规则排版（小排版）的抽象语法**
- 先做一套自己的小图标，允许自由排布；允许文本与图标组合，但**要切换排布方式**。
- 抽象表示：圆形 = 图标；矩形 = 不同字重和间距的文本行。
- 四种变换：①对齐方式（左/右对齐）；②调换文本顺序；③调换文本与图标的顺序；④调换文本重心（哪一行最长/最重）。组合这些变换得到丰富但同源的信息块（作者列了 6 种实例，各配一个抽象线框）。

**各张的原则**
- 001 负空间：刻意把左侧控制得很干净，用左侧空白去衬右侧多色混合；“秩序 vs 动态”同屏共存是主动设计的。色条延伸表达力量和冲突感：①把扎眼的颜色混在一起；②形状的位次差、顺序差、前后混合；③方向指引（箭头）。小元素：大小本身容易让版式乱，办法是加强元素之间的联系形成“区块”；但主体和小元素之间要保留“真空”，因为大字 OVER 已经和人物产生联系。可以允许一点小细节打破完全的空白。
- 002 分层：竖幅，强化“指引”，小排版趋于规整；彩色条纹的灵动让“流动性”成为后面的主题；人物主体过深时要处理留白和信息量。
- 003 信息密度的权衡：把统计表格和跳远融合；控制信息密度是留白的重要手段——“主动舍弃信息密度”。色带方向上用三段式递增大小（被撞击的边缘越往后越小）表达运动和阻碍。侵入比例：图像与主体的侵入关系，贴合手臂处侵入多、头部侵入少，腿部一处多一处少；偏心的安排打破透视，使三者不被看成一个整体，前后关系更清楚。动态模糊下人物拖影不应和人物完全一致，要考虑着地空间（“滞空感”）。
- 004：票根三联，规则信息排布参考现实票根即可；继续“突破画布”——“画框外的叙事”。
- 005 非对称构图：这是信息最少的一张，追求简单但有趣。更醒目的信息贴近画布边缘会对边界形成压迫，不那么醒目的信息压迫轻；所以**要维护不同醒目程度的信息到边缘的距离**，并把信息集中到右侧，让人更关注右侧。扫描线纹理来自动作形成的扫描曲线（置换+深度图）。
- 006 取舍：原本用大面积黄蓝三角形色块打底，最后画面脏乱的主因是**色块面积太大**；改为色条和曲线——方向感明确、占地足够小；“用色大胆也意味着用色混乱的问题”，靠明暗关系或给素材去色/改色修正。最终放弃了过于激进的重复与中心对称，为了留白。
- 007 三点构图：画面藏了两个三角形，几何框选覆盖大部分内容；把人物和文字当主体，主体也是三角形，三个三角形分别占上中下部，所以“塞得满”；三点布局的问题是其余部分都处在真空，要补齐空缺来支撑中心（水花素材的作用）。透视带来运动感：三角形碎片由宽收束到窄，最后汇聚到圆形，是重要的视线指引；观众视角直盯人物主体核心。
- 008：竖幅，人物倒立 + 色带曲线。

模板：网盘有下载链接（未取）；原理可抽象成“信息块语法”模板（见 §3 T6）。

### 2.3 新手入门问答（/answer/）与《如何开始平面设计》（/beginner/，2026-10-22）

- 画面空：①**动线**——元素沿视线移动方向排布，用颜色或文字引导目光；新加的元素要和动线有关，不加无关装饰。②**版式**——先定主体，其他元素围绕主体；空白本身可以是设计的一部分；可以用极浅的纹理提升质感。
- 作图流程四步：需求关键词 → 找主题定基本构图；收集构图匹配的参考，判断哪些全借、哪些部分借，记关键词；制作中想表达怎么实现、是否需要补素材或重调构图；卡住就休息、回看参考、**重新确认节奏**。做完和需求方对齐。
- 氛围/照片素材：先试黑白（饱和度、曝光降到最低再慢慢拉回），再用渐变映射重新上色或用色相/饱和度改局部；快速融入：颜色查找滤镜不透明度降到约 30–50%，或“匹配颜色”以背景为源；两者都别直接作用于人物，至少用蒙版把肤色隔开。
- 背景补完度三法：①人物排列——立绘降透明度放背景，进阶是去色提明度当纹理；②几何元素——填充 + 随机脚本铺小几何形；③摄影/纹理素材——木刻或颗粒处理、降饱和做衬底。
- 进步与风格：先能精准复刻别人的风格，自己的风格“水到渠成”；表达是核心，技巧是手段，堆小技巧难带来整体提升。
- 进阶：建立设计系统（色板、字体规范、间距标准）保持一致；从用户视角思考。
- 推荐练习项目：视频封面、人物排版、吧唧、海报。推荐书：《写给大家看的设计书》《设计中的设计》《平面设计中的网格系统》。

## 3. 可做成模板资产的（#261）

每个模板写成：id、画布、槽位（含最大长度）、参数、可测检查。数值来自上文，标“推断”的是我从作品归纳的，需要渲染后再定。

### T1 `cover.strategy-video`（攻略视频封面）— 首选
- 画布：两版同出——16:9 1920×1080 与 16:10 2560×1600（命名按像素，不写“4:3”）。
- 槽位：`stage_code`（关卡代号，2–8 字符，最大字号层）；`squad_line`（队伍/条件，≤10 汉字）；`mode_tag`（突袭/险地作战/HARD MODE，≤6 字）；`operators[]`（1–6 张透明立绘）；`micro_en[]`（2–6 条英文微排版，每条 ≤24 字符）；`series_mark`（右下系列/作者签）。
- 参数：`theme`（活动皮肤：palette 3 色 + 装饰语言 id）、`code_treatment`（实心/描边/拆字破碎/像素）、`operator_layout`（单人偏侧/双人对称/多人并排卡片）、`intrusion`（立绘侵入代号的程度 0–1，推断）、`bg_saturation_max`（背景饱和度上限）、`shadow`（大小/不透明度，默认极小）。
- 检查：主信息（code + squad + mode）落在 16:9 ∩ 16:10 交集安全区；色相跨度 ≤120（除非 theme 声明对比）；背景饱和度 < 前景（人物/字标）；字距：标题 −50…−100、正文 0；文字不被立绘遮挡到不可读（读序检查）。

### T2 `stream.room-kit`（直播间套件）
- 画布：1920×1080 × 2（主界面、待机页）+ 弹幕 CSS。
- 槽位：`brand_tag`（左上，≤12 字符）、`room_index`（编号）、`standby_title`（直播准备中，≤8 汉字）、`standby_en`（LIVE NOW / LIVESTREAM IS LOADING）、`topic_line`（TOPIC TITLE & CORE IDEA，≤40 字符）、`chat_title`（CHATROOM）。
- 参数：主窗口 / 聊天栏宽度比（约 3:1）、圆角、主题皮肤（palette、材质：毛玻璃/丝绒纸张/工业）、弹幕 CSS 变量组（身份 6 级颜色、礼物 6 档颜色、描边档位、基准字号、字体栈）。
- 检查：主窗口透明区尺寸与 OBS 源一致；弹幕在任一皮肤下对比度达标；CSS 只改变量不改结构。

### T3 `card.qa-tutorial`（3:4 问答教程卡，排雷手册式）
- 画布：1080×1440。
- 槽位：`q_no`、`q_title`（≤12 汉字）、`a_no`、`a_title`（≤12 汉字）、`body`（≤90 汉字，3–6 行）、`examples[]`（1–5 个虚线框示例，每个带 ✓/✗/编号）、`footer`。
- 参数：外框色 / 内底色 / 字色（默认三色 H49/H47/H21 一组）、角钉开关、引号装饰开关。
- 检查：正文字距 0；行间空隙 ≥ 字间空隙，同字重多行 1.5–2 倍；三色色相跨度 ≤120。

### T4 `card.endfield-tutorial`（终末地工业风教程卡）
- 画布：1080×1440。
- 槽位：`title`（方括号包裹，≤6 汉字）、`kicker_en`（GRAPHIC DESIGN TUTORIAL COLLECTION）、`steps_text`（≤80 汉字）、`figure`（截图/前后对比）、`callouts[]`（黄色胶囊标注 ≤6 字）、`before/after`、`footer_mark`。
- 参数：强调色（默认荧光黄 #FFFF10，可换）、底灰、黄条位置。
- 检查：强调色面积占比上限（只出现在标题条、胶囊、页脚条）；其余必须灰阶。

### T5 `card.operator-grey`（灰阶角色卡）
- 直接对应站上的生成器字段：name_cn、name_en、hp、atk、def、res、block、redeploy、cost、talent1–2、skill1–3、portrait。
- 参数：灰阶程度、强调色、数值栏样式。检查：空值占位、长技能名截断/换行。

### T6 `layout.info-block`（信息块语法，来自 JUMP[OVER]）
- 不是一张图，而是可复用的“小排版”组件：输入 = 若干 `icon`（圆）和若干 `text_line`（矩形，带字重/长度）；参数 = `align`（左/右）、`order`（文本顺序）、`icon_position`（前/后/上/下）、`emphasis_line`（哪行最重）。
- 用法：封面/海报里的英文微排版、角标、系列签都从这里生成，保证同源但不重复。
- 检查：同一画面内的多个信息块至少在一个算子上不同（避免复制粘贴感）；块与主体之间保留空白（“真空”）。

### T7 `texture.*`（质感层）
- `texture.dot-matrix`（点阵/瓷砖：格子 4px，阈值 224/104 或 254/104）、`texture.recolor`（高反差保留 + 线性光 + 底色）、`texture.acid`（差值反相 + 表面模糊 5/15 + 高光半调）、`texture.silhouette`（去阴影剪影）、`texture.scanline`。以 SVG filter 或预渲染 PNG 实现，作为可开关层喂给 T1/T2。

| L1 `layer.texture` | 加质感层（T7） | 无质感层 | 盲评“质感”；文字区噪声（不得降低可读性） |
| L2 `layer.theme-skin` | 按主题套色板与装饰语言 | 只用中性色 | 风格 ΔE；盲评“像这个系列” |
| L3 `layer.endfield-shell` | 套终末地外壳（`//`前缀、括号标题、竖黄条、角标） | 无外壳 | 风格识别率（盲评选“像终末地”）；强调色面积占比 |

建议的消融场景（对应 #260 的 brief）：
- S1 攻略视频封面（T1，暗色主题，6 字内代号 + 队伍行 + 突袭标签 + 2 名立绘）。
- S2 浅色短文本卡（T3，Q/A 一题）。
- S3 长文解说卡（T4，6 步教程，含截图位）。
- S4 直播间待机页（T2，换两套皮肤）。
- 每个场景：full / −R* 单条 / −全部 R / 裸模型；N≥5；决策规则先写好（例如：某条规则关掉后可测信号恶化且盲评胜率下降 ≥10 个百分点才保留）。

## 5. 品味与韵律：原则 vs 固定像素配方

主人的判断（规则叠加不做消融就缺节奏和品味）在这个站上能看到对应的证据：作者自己的“好图”几乎都来自**关系型原则**，而“配方”只负责质感。把两类分开：

### 5.1 关系型原则（决定节奏，应作为排版判断，不应写死数值）
- **一处安静，一处热闹**：负空间与复杂区互补；“秩序感与凌乱感并存”是主动选择（JUMP 001）。
- **主体先行**：先定主体，其他围绕；空白本身是设计（入门问答）。
- **动线**：所有新增元素沿视线路径；不在路径上的装饰不加（入门问答）。
- **密度是留白的手段**：主动删信息；信息最少的一张最好玩（JUMP 003/005）。
- **醒目度与边距成反比**：越重的信息越不能贴边，否则压迫边界；轻信息可以靠边（JUMP 005）。
- **侵入要偏心**：前景与文字/背景的重叠局部多、局部少，才能拉开前后（JUMP 003）。
- **用线代面**：色块面积大就脏，换成方向明确、占地小的色条和曲线（JUMP 006）。
- **三角支撑与补空**：三点/三角构图塞满后，剩余区域是真空，需要少量素材补齐支撑（JUMP 007）。
- **同源变化**：小排版由同一套语法生成，每块换一个算子（JUMP 规则排版）。
- **比例递进**：三段式递增大小表达运动与阻力（JUMP 003）；字号/字距按角色分级（排雷手册 Q2）。
- **色相收敛、饱和度分层**：色相跨度收窄，彩色只给主体（排雷手册 Q6）——这是“统一感”的来源，而不是某个具体色值。
- **卡住就回去确认节奏**：作者流程里明确有“重新确认节奏”一步（入门问答）。

### 5.2 固定像素/参数配方（决定质感，可以写死，作为可开关层）
- 拼缀图方形 4 / 凸现 0；混合颜色带 224/104、254/104；高反差保留 95.6 px；表面模糊 5/15；颜色范围 20%/190；色阶 0/1.00/170。
- 教程卡外壳：1080×1440、黄框 #DFBD42、奶油底、角钉；终末地壳：#E7E7E7 + #FFFF10 黄条、方括号标题、`▼ DESIGN TUTORIAL`。
- 阴影面板默认值与“先归零再加”。
- 字距具体数：−100 / −50 / 0。

### 5.3 对 design-pipeline 的含义
- 5.2 的配方可以放进模板库，按 id 渲染、按参数调；它们**不会**自己带来节奏。
- 5.1 的原则不宜写成“每张都要满足 N 条”的清单（那正是主人担心的堆规则）；更适合作为**少数几条可测的关系约束**（R12–R17）+ 盲评，进入 #260 的消融，用数据决定留哪几条。
- 作者的方法论本身就是“做加法，然后取舍”（JUMP 006 的取舍、阴影的“先归零再加”）。对应到流水线：先生成最小版本，再逐层加，每加一层都要能在信号上说明它的作用——和消融评测是同一个思路。
