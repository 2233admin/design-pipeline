# 宣传动画能力：本轮总结

本轮把“做一个宣传动画”落实为一套先看参考、整理素材、编排镜头与声音，再制作和验收的流程。
最终交付是 SeedController 的 32 秒 HTML 宣传片《想象，自有联系》。用户在 2026-09-22
观看后表示基本没有大的问题，并要求总结和提交 PR。

## 为什么这次成立

- **参考具体到动态镜头。** 观察用户提供的《SEAM》中的镜头尺度、主体运动、冷灰质感、
  局部特写与细线标记，再确定适合画布产品的表现方式。
- **画面有真实的内部运动。** 复用产品现有的城市、夜间骑行和月下钢琴视频；移动的主体和
  摄影机提供主要动势，图形用于解释局部和创作关系。
- **产品关系在镜头里展开。** 月下钢琴从全屏作品退入画布节点，接入素材、提示词和创作指令；
  选中的视频节点再展开成全屏作品，连接产品用途和最终成果。
- **声音参与时间安排。** 32 秒原创电子器乐与主时间轴同步，主要剪辑点按乐句编排。
  页面提供明确的有声播放入口、静音和音量控制。

改进的关键是参考、素材、镜头动作和声音形成了同一个制作方向。更换模板、增加缓动或保持
物体连续运动，单独都不足以决定宣传片的感觉。

## 固化到工具里的能力

| 环节 | 本轮改动 |
| --- | --- |
| Job Dispatcher | 普通的“宣传动画”“推广动画”及英文 promo animation 能进入产品宣传片路线，保留 HTML 等交付形式 |
| 创意方向 | 新增产品宣传片约定：动态参考和现有素材优先，确定产品动作、视觉语言与声音方向后再选模板 |
| 制作 | 先完成有代表性的 6–10 秒声画片段，再扩展全片；无需用户掌握 motion graphics 术语 |
| 验收 | 分开记录技术检查、创意判断和用户接受状态；静帧或测试通过不能证明宣传片效果成立 |
| 动画证据 | 补齐 receipt schema 和边界校验，提供可选的严格 lifecycle 覆盖；保留旧 receipt 的 timing-only 兼容路径 |

制作约定见 [product-film-direction.md](../skill/references/product-film-direction.md)。
技术动作的 lifecycle 检查属于运行保障，宣传片的创意验收另行进行。

## 可运行的交付

推荐观看 [Field Notes](../experiments/seed-film-reference/README.md)：

```sh
node experiments/seed-film-reference/server.cjs
```

打开 <http://127.0.0.1:4176/>，点击 **播放影片 · 开启声音**。

保留三组历史对照：基础动效展示（4173）、ASCII 分场样片（4174）、连续画布概念（4175）。
后两者已标记为未被用户接受的宣传方向，供观察问题与改进使用。

## 证据与边界

- 整片连续播放及 20 个时间采样已检查；抽样的最大音画时差约 51 毫秒。
- 播放、重播、拖动进度、静音、全屏和 390px 手机布局已检查；修复了连续拖动后的目标帧定位问题。
- 仓库 QA 通过：676 项测试，以及 11 项安装包测试；打包、隔离安装与 CLI 自检通过。
- 当前代理工具不提供音频输入，因此配乐的主观听辨没有被代理独立验证。记录的是实际播放、
  同步和电平测量；用户对本版的总体反馈另行记录。
- 画布画面是宣传概念演绎，素材来自现有产品展示视频，不代表一次真实生成任务的录屏。
  本轮未修改 SeedController 生产应用，也未调用生成服务或部署站点。
