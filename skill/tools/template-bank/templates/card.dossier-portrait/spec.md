# card.dossier-portrait — 竖版档案卡（角色/物品）

> 测量依据，原样来自调研（`docs/research/arknights-endfield-template-study.md`）。槽位上限、参数范围和调色板以同目录 `manifest.json` 为准；`template check` 量出来后改过的地方列在其 `changesFromStudy`。

画布 1000×1500（2:3）。来源：明日方舟 DOSSIER_PORTRAIT 6 张（AK038 细测）+ 终末地武器档案 3 张（EF084 细测，作为 `variant` 说明）。

## 什么时候用
一张图讲清一个对象：名字、属性、立绘、能力说明。社交平台竖图、长图首屏。

## 槽位与上限
| 槽位 | 类型 | 上限 |
|---|---|---|
| name_cjk | 文本，思源黑体 Heavy | ≤5 字 |
| name_latin | lettering（反白，在深色条上） | ≤14 字符 |
| rarity_0..5 | 自绘三角 | 1–6 |
| attr_label_i / attr_value_i | 文本 | 4 行；标签 2 字，值 ≤18 字 |
| figure | 图片 | x 0.25–0.85W，y 0.08–0.71H，脚落在分隔线上 |
| quote / credit_i | 文本 | 32 / 18 |
| talent_title / talent_body | 文本 | 10 / 88（4 行×22） |
| skill_icon_k / skill_text_k / skill_note_k | 图 + 文本 | 3 行；78 / 26 |
| logo / maker_mark | 图片 | 上中 / 左下 |

## 量出来的比例
- 外框内缩 0.042W（AK038）；名字 x 0.052W、y 0.15–0.19H；属性行 x 0.042–0.30W、y 0.24–0.30H；分隔线 y 0.712H；技能区 y 0.73–0.91H。
- 6 张中名字在左上 5/6，标题中心 y 中位 0.172H，面积中位 1.4%（名字小，人物占 55% 宽）。
- 色彩：中性像素中位 0.92（所有类别最高），强彩只有红色系技能图标（彩色簇 82% 落在 h 0–30°）。
- 终末地武器变体（EF084，905×1600）：左侧竖色带宽 0.21W 放竖排大标题，名牌 x 0.48–0.92W、y 0.47–0.52H，深色说明面板从 0.76H 开始。

## 关系 vs 装饰
- **关系**：上 1/3 身份信息、中部立绘、下 1/4 说明，三段由一条分隔线切开；文字全部左对齐到框内缘 + 1%。
- **装饰**：范围格子图标、角标、底部大号几何水印（模板不画）。
