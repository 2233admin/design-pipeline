# kv.outfit-title-left — 时装/系列 KV，标题列在左，人物居中偏右

> 测量依据，原样来自调研（`docs/research/arknights-endfield-template-study.md`）。槽位上限、参数范围和调色板以同目录 `manifest.json` 为准；`template check` 量出来后改过的地方列在其 `changesFromStudy`。

画布 1920×1080（16:9）。来源：明日方舟 KV_OUTFIT 13 张（逐张目测标注 13/13）+ 测量。

## 什么时候用
单个角色/单件商品的系列展示：浅底、一个人物、一列标题、少量英文小字。不适合多人、强叙事或需要大面积强调色的场景。

## 槽位与上限
| 槽位 | 类型 | 上限 |
|---|---|---|
| logo | 图片 | 0.11W×0.06H，左上安全区角（9/13 在左上，4/13 在右上） |
| series_label / series_sub | lettering / 文本 | 18 字符 / 28 字符 |
| title_latin_1, title_latin_2 | lettering（自绘字） | 各 ≤10 字符；以 `set_text` 返回宽度 ≤ 0.30W 为准 |
| title_cjk | 文本，思源宋体 Heavy | ≤8 字 |
| item_line | 文本 | ≤20 字 |
| meta_label_i / meta_value_i | lettering / 文本 | 标签 ≤10，值 ≤32 |
| figure | 图片（透明抠像） | 中心 x 0.56，宽 0.42W，可出血到底 |
| copyright | 文本 | ≤40 |

## 量出来的比例（参数）
- 标题在左侧：13/13；标题列左缘 x0 中位 0.04W（p25–p75 0.03–0.05）；标题中心 y 中位 0.50H（0.435–0.525）；标题区面积中位 8.1% 画布。
- 标题与人物横向重叠 >30%：0/13（标题列不压人物）。
- 人物中心 x 中位 0.55，宽 0.40W（0.30–0.50）。
- 主色（k-means Lab 最大簇）：L* 中位 89.7，C* 1.5（浅中性底：13 张中 8 张最大色簇 L*>70；其余是暗底变体，换 bg 参数即可）。
- 中性像素（C*<10）占比中位 0.64；强彩像素（C*>50）中位 0.023；彩色像素的色相圆标准差中位 14°（单一主题色相）。
- 竖排标题 3/13（可选变体：title_latin 改成竖条）。

## 节奏关系 vs 固定装饰
- **关系（要保留）**：标题列与人物不重叠；标题左缘 = logo 左缘 = 元信息左缘（同一左对齐线）；整幅只有一个主题色相，强调色面积 ≤3%。
- **装饰（可关）**：背景水印大字（`watermark`）、底部细线、金色短线。

## 调色板角色
bg 浅中性 / ink 近黑 / ink2 中灰 / accent 唯一主题色（只出现在短线与少量标记）/ water 比 bg 暗 4–6 L* 的水印色。
