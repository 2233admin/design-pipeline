# card.void-line: Void card: one small line in a black frame, a red dot, a corner number

> Measured basis. Slot budgets, parameter ranges and palette are authoritative in `manifest.json`; the style pack (`styles/shinbo/style.json`) owns the font roles, grammar, materials, motion grammar and checks.

Canvas 1920x1080 (1920x1080, 1280x720, 3840x2160). Source: Nocturne Corridor c09 final (samples c09-black-void).

## When to use
A pause beat: one short sentence in a large void.

## Slots
| Slot | Kind (font role) | Budget |
|---|---|---|
| line | text (head) | <= 14 |
| number | text (num) | <= 4 |

## Measured
- line 34px tracked .42em centred at 520px; grey number 22px (5.2:1 on black)

## Relations vs decoration
- **Relation**: Everything but the line is void; the number goes to the far corner in grey.
- **Decoration**: Red dot below the line.
