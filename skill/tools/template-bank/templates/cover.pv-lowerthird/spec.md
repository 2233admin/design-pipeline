# cover.pv-lowerthird — 视频封面，logo + 标题同一行居中在下三分之一

> 测量依据，原样来自调研（`docs/research/arknights-endfield-template-study.md`）。槽位上限、参数范围和调色板以同目录 `manifest.json` 为准；`template check` 量出来后改过的地方列在其 `changesFromStudy`。

画布 1600×1000（16:10），同时标出 16:9 中心裁切框。来源：明日方舟 PV_COVER 8 张（1146×717 / 960×600 / 1728×1080）。

## 什么时候用
活动/版本宣传视频的封面：整幅场景图，信息只占下三分之一，一个“宣传PV”标签条。

## 槽位与上限
| 槽位 | 类型 | 上限 |
|---|---|---|
| key_art | 图片 | 全出血 |
| logo | 图片 | 0.22W×0.12H，与标题同一行（4/8 如此） |
| title_cjk | 文本，思源宋体 Heavy | ≤9 字 |
| title_latin | lettering，宽字距 | ≤22 字符 |
| pv_label | 文本 | ≤6 字，放在深色条中，两侧短竖条 + 横线 |
| copyright | 文本 | ≤30 |

## 量出来的比例
- 标题居中：6/8；标题中心 y 中位 0.72H（p25–p75 0.71–0.725，非常稳定）；标题区面积中位 16%（所有类别里最大）。
- 标题压在人物上 >30%：5/8 → 模板默认开 `scrim`（底部 55% 黑色渐变到 72%）。
- 色彩：C* 中位 7.2，强彩像素中位 0.3%，整体是低饱和场景色 + 白字。
- 16:9 裁切：标题带 0.60–0.86H 落在 16:10→16:9 中心裁切的保留区（0.056–0.944H）内。

## 关系 vs 装饰
- **关系**：logo 与标题共用一条基线带；标签条居中于标题带下；信息只在下三分之一。
- **装饰**：标签条两侧的竖条与横线。
