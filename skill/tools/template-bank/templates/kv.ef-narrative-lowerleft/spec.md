# kv.ef-narrative-lowerleft — 终末地式“栏目 // 方括号标题 + 荧光标语条”，人物在右

> 测量依据，原样来自调研（`docs/research/arknights-endfield-template-study.md`）。槽位上限、参数范围和调色板以同目录 `manifest.json` 为准；`template check` 量出来后改过的地方列在其 `changesFromStudy`。

画布 1920×1080。来源：EF060 细测 + 终末地 KV 16 张统计。

## 什么时候用
深色、叙事向的单人内容封面（角色故事、剧情章节、开发日志）。信息在左下堆成一列，人物胸像在右。

## 槽位与上限
| 槽位 | 类型 | 上限 |
|---|---|---|
| logo | 图片 | 方块字标 0.075W×0.14H，左上 |
| kicker_icon + kicker_slashes + kicker_cjk | 色块 + lettering `//` + 文本（思源黑体 Heavy） | 栏目名 ≤6 字 |
| bracket_open / title_cjk / bracket_close | lettering `[` `]` + 文本 | 标题 ≤8 字；右括号位置 = 标题起点 + 字数×字号（全角 1em 推算），实际填字后按渲染宽度重算 |
| tagline_bar + tagline | 强调色条 + lettering（字距 +900/1000 em） | ≤36 字符 |
| figure | 图片 | x 0.45W 起到右边 |
| micro_marker | 小方框 + 引线 + 极小字 | 0–3 个 |
| tick 三色短条、条码短条 | 装饰 | 可关 |

## 量出来的比例（EF060，1600×900 实测换算）
- 公共左对齐线 x = 0.047W：logo、栏目、标题括号、标语条四者同一左缘。
- 上边距 0.075H，下边距约 0.063H，右边距 0.047W。
- 栏目行 y 0.57–0.63H；标题 y 0.655–0.80H（字高约 0.135H）；标语条 y 0.828–0.852H，宽 0.047–0.53W。
- 标题文本栈整体在 x 0.047–0.57W × y 0.56–0.86H。
- 终末地 KV_OPERATOR 4 张中 3 张有荧光黄（L*>75, C*>60, h_ab 92–115），强彩像素中位 0.116（明日方舟同类 0.018）。

## 关系 vs 装饰
- **关系**：四个元素共用左缘；“栏目 → 标题 → 标语”字号 1 : 2.6 : 0.2 的跳跃；荧光色只在图标块和标语条上。
- **装饰**：红色光幕、十字准星微标、三色短条、条码。
