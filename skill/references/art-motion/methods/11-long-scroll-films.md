# 11 · 长卷穿越片：一个人从左走到右，穿过一幅幅名画

《穿越名画》（2026-10-05，123.7 秒，24 个世界）用的做法。和艺术史速通（同一个房间换画风）不同，这里是**一条横向长画卷**：每个世界是一段横向延展的画，首尾相接；主角一直往右走，跨过边界那一刻，他的画风和世界一起换。

本项目的长卷机制是 `tools/art-motion/scroll.js`（用法见[长卷工具](../../../tools/art-motion/scroll.md)）：调用方定义每段世界，`scroll.js` 负责把段首尾相接排开、插入互动停顿、按绝对时间求主角与相机状态，并按层画（背景 → 主角 → 前景 → 接缝）。静帧与整段由调用方在自己的 Canvas 渲染器里用 `scene.draw(ctx, t)` 合成；`scene.stateAt(t)` 同一时刻返回同一状态，可以倒序 seek 抽帧核对。

## 结构（`scroll.js` 的段接口）

| 要管的事 | 在 `scroll.js` 里 |
|---|---|
| 段的顺序 | `segments` 数组的顺序 |
| 段宽与地面 | 每段 `width`、`groundAt(x)`；相邻段在共同边界上的地面高度必须一致（或显式给 `groundTolerance`） |
| 时间轴（走 → 停下互动 → 走） | 段的 `interactions`：`at`（段内世界坐标）、`duration`（秒）、`poseAt(localSeconds, globalSeconds)` |
| 主角行进 | `start`、`speed`，需要离开地面时用段的 `actorAt` |
| 相机 | 调用方的 `camera(state, viewport)` |
| 按边界裁开的主角 | `actorBounds` ＋ 每段的 `drawActor`/`clip`：主角跨边界时，每个相交的段各用自己的画法画一遍 |
| 背景、前景遮挡、边界 | `drawBackground`、`drawForeground`、`drawSeam` |
| 角色帧库 | 调用方自备：每个动作 8 张透明 PNG＋元数据（每帧脚底锚点、尺寸、是否离地；站立身高的像素数） |

## 加一段

1. 写一个段对象 `{ id, width, groundAt, interactions, drawBackground, drawActor, drawForeground, drawSeam }`，接口见[长卷工具](../../../tools/art-motion/scroll.md)。世界本身用代码画，优先把 `tools/art-motion/engine/scenes/<id>.js` 里现成的风格场景改造成横向延展的版本（段宽 2000–2800）。
2. 生角色帧：每个世界一张「走路 8 帧」，有互动的再加一张「互动 8 帧」，按该画风让生图模型重画、绿幕、切帧（`tools/art-motion/assets.cjs` 的 `keyFiles`/`splitFile`，做法见 10 号），放进项目自己的帧库目录，写好每帧锚点元数据。
3. 把这段放进 `segments` 数组的正确位置（按年代排序）。
4. 渲静帧核边界两侧（用 `scene.layout()` 的段边界找时刻），再对同一时刻重渲比对确定性，必须逐像素一致。

## 关键约定（全片统一，写死在调用方的骨架常量里）

- **地面线 760，主角站立身高 300，主角在画面 720px 处。** 段两端（x=0 和 x=width 附近 ±150px）`groundAt` 必须回到 760，地平线尽量落在 480–560，跨边界时两边才接得上。中间可以有桥、台阶（`groundAt(x)` 返回对应高度）。
- **所有事件相对「互动开始」定时。** 用互动 `poseAt(localSeconds, globalSeconds)` 的 `localSeconds`（从互动开始算）驱动动作；不要写「进段后第几秒」。全片步速后来从 330 提到 560，按这条写的段一处都不用改。
- **镜头只进不退。** 相机目标 = 主角 x − 720 ＋ 互动时向前让出的提前量 `lead`，取历史最大值再做高斯平滑，所以全程单调、停与起都不顿。互动想让镜头别动，就让 `lead` 为 0。`camera(state)` 要只由时间/状态算出，倒序 seek 才一致。
- **每段的边界用该段的签名语言画**（`drawSeam`：纸边、像素棋盘、彩块分栏线……），这是速通片「转场 = 下一个风格的签名语言」在长卷里的版本。
- **主角走路帧率随步速同比例**，8 帧一个步态循环；需要再过一层该画风的材质时，在该段的 `drawActor` 里自己合成，不改共用库。
- **配乐**：画面先定，音乐后配。每段放整数拍，逐段把速度在 86–104 BPM 之间微调，让每条边界都落在小节第一拍（实测 24 条边界最大误差 11.7ms）；人耳听不出 ±8% 的逐段速度差。
- **不要替主角加没要的梗。** 实验骨架里有「帽子上摞纪念品」的功能（`scroll.js` 里对应 `earnedItemsAt`），容易与场景争夺视觉注意力，默认不开。

更多证据和数字见 `07-proven-practice.md` 第 36–38 条。
