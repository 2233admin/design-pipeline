# ReplayBar

> 回放中整屏叠 `scanline`（提示"这不是实时"），定位到的时刻在图上加一组 `bracket`（signature.md）。

回放控制条。进入回放的那一刻，整个 LinkGroup 的面板切到回放时钟；实时时钟仍在右侧只读显示，两者永远不混。

## 结构

- 左：`REPLAY` 点阵标签（amber）；后退 / 播放·暂停 / 前进三个 28px 按钮。
- 回放时钟 LCD（amber 数值）；时间轴（点阵填充 = 已播，`signal-orange` 发光游标，amber 小块 = 事件标记：异动、成交、告警）；倍速 1× / 4× / 16× / 64×；右：LIVE 时钟 LCD（`ink-300`，只读）。
- 整条外框 `signal-orange-dim`，和实时面板区分。

## 交互

- 空格 播放/暂停；← → 跳 1 分钟（⇧ 10 分钟）；点击事件标记跳到该事件；拖动游标跟手，松手 `settle`。
- 倍速切换即时生效；播放中拖动游标自动暂停。
- 回放时间写入 URL（TanStack Router），分享链接可定位到同一时刻。
- 退出回放：所有面板 `gentle` 回到实时，LinkContext.range 恢复。

## 状态

- 数据回补中：时间轴未回补段用 `ink-400` 斜纹，游标不可进入。
- 回放中禁止实盘下单：下单命令返回"回放模式"错误，梯子点击下单拨杆灰掉；模拟下单允许（标记为回放成交）。

## 规则

- 回放时钟是独立时钟，不是把实时时间往回拨。
- 回放成交和实时成交永远不混流；回放产生的模拟成交带 `replay` 标记。

## 谁提供什么

- 组件：clock、live、range、speed、events、playing、onSeek、onSpeed。
- 数据：回放服务按时钟推送同一格式的 batch，经 MarketAPI 的回放通道。

## ATAS 对照补齐（2026-10-03，atas.md §2.8）

- 步进模式三选一：bar / period / date。
- **保真度角标**：回放适配器声明 `L2 真实 / L2 生成 / 全生成` 三种数据模式，面板常显，不隐瞒生成数据。
- Replay Account 独立：回放成交进 TradeStats 时打 `REPLAY` 来源标，与实盘 / RUN 三分。
- 多品种同步回放（并发数由回放服务决定）；回放中锁连接、图表头显示 Historical（已有）。
