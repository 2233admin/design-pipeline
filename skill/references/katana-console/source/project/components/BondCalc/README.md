# BondCalc

债券计算器：价格 ↔ 收益率互算，久期 / 凸性 / DV01，G / Z 利差（对 YieldCurve 选的基准），现金流表；可转债另加转股价值、溢价率、纯债价值、Δ、强赎 / 回售触发距离。计算在 Worker（QuantLib-python 或 Fincept Solver 那类库的 TS 移植），现金流与条款来自数据平台。

## 结构

- 顶行：代码·名称 · 剩余期限 / 票息结构 / 评级 · 账户持有。
- 左框输入：价格、YTM、结算日、基准曲线（LCD 输入，改任一项其余重算）；输出键值：修正久期、凸性、DV01、G / Z-spread、应计。
- 右框：可转债块（转股价、正股价、转股价值、溢价率、纯债价值、Δ、强赎 / 回售距离 amber 接近时）；现金流表（日期 · 内容 · 金额）；条款行（回售 / 下修）`ink-300`。
- 普通债券右框只有现金流与关键日期。

## 交互

- 改价格 → YTM 滚动，反之亦然；改基准曲线 → 利差重算。
- 点击现金流行 → Calendar 定位；点击强赎 → AlertCenter 规则（正股价距触发 ≤ 5%）。
- 「加入持仓影响」→ 按账户持有张数算 DV01 合计进 RiskBoard 利率敏感项。
- 情景：平移 ±50bp 的价格变化一行（Worker 即算）。

## 规则

- 条款（票息递进、回售、下修、强赎）是数据，不硬编码；可转债规则属 Profile（CN-CB）。
- 结算日与 T+N 来自 Profile。
- 输出标注模型（现金流折现 / 二叉树）；可转债 Δ 标 `估`。
- 不做评级颜色。

## 谁提供什么

- 组件：bond（terms、cashflows、rating）、inputs、curve、holdings、onChange、onScenario。
- 调用方：数据平台条款 + YieldCurve 基准 + 定价 Worker。
