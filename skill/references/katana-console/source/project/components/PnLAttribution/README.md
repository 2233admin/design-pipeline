# PnLAttribution

盈亏归因：今天（或选中区间）的钱从哪来。零轴水平条形，按品种 / 账户 / 策略 / 资产类别切维度。自研 Canvas 2D（行数多时）或 DOM（≤ 12 行）。

## 结构

- 顶行：维度 Segmented（≤ 4）· 区间 · 右侧合计 LCD（数字 `pnl-*`，带 `EST` 与账户集合点阵标）。
- 每行：标签（代码 + 名称，或账户短码，或策略名）· 零轴条 · 数值。行高 22，列间 12。
- **方向用位置表达**：正值向右、负值向左，零轴 1px `line-200` 居中。条本身 `ink-200` 点阵纹理，不用红绿；只有右侧数字用 `pnl-up / pnl-down`（涨跌色不上面积，readability §14）。
- 当前 LinkContext 品种的条转 `signal-orange` 纹理。
- 排序按 |贡献| 降序，正负分两组：正组在上、负组在下，组内各自降序。
- 超过 7 项折进 `其他 ×n`（工作记忆）；费用·税永远单独一行在底部。
- 刻度对称（±max），页脚写出；不画网格、不画刻度数字。

## 交互

- 悬停行 → tooltip（LCD 窗）：绝对值、占比、持仓数、所属账户；点击行写 LinkContext。
- 切维度：条长 `gentle` 过渡到新值，行按新排序重排（`snappy`，≤ 300ms）；留下的行不重新上色。
- 区间：今日 / 本周 / 本月 / 自定义（同 LinkContext.range）。

## 规则

- 不用瀑布图（阅读要跟踪累计基线，认知负荷高）；不用饼图。
- 不用颜色区分账户或策略——标签说清楚就够。
- 已实现 / 未实现不在这里拆（那是表格的事）；这里只回答"谁贡献了多少"。
- 研究账本不计入；显示在页脚声明。
- 实时更新时数字滚动、条 `gentle` 跟随，**不做任何庆祝性反馈**（readability §25）。

## 谁提供什么

- 组件：items[]（key、label、value、kind、accounts[]）、dim、range、total、focusKey。
- 调用方：PositionBook 共享聚合器输出 + 费用快照。
