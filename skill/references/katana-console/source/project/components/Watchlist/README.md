# Watchlist

自选：DataGrid 的一个预设。多张列表、分组行、异动灯列、迷你 30 分钟柱、持有账户标记。它是 LinkGroup 最常见的**写入端**——点一行，整组面板跟着换票。

## 结构

- 顶行：列表 Segmented（≤ 5 张，更多进下拉）· 行数与排序 · 右侧写入哪个 LinkGroup（色标 + 组名）。**列表切换不是 tab**，不保留各自滚动位置以外的任何状态。
- 列（预设，可配置）：异动灯 · 代码·名称 · 现价 · 涨跌 · 量比 · 30m 迷你柱。行高 `row-tight`。
- 分组行（点阵 `ink-300` + 计数）：默认按「持有 / 观察」自动分组；也可按行业、按用户标签。持有的票名称后点阵标持有账户短码（`A B`），来自 PositionBook 共享的 Book。
- 异动灯：该票命中监控规则时 orange 亮 + `radar-ping`，30s 后灭；灯列同屏 ≤ 3 盏亮（StatusLED 预算）。
- 迷你柱 6 根 = 最近 30 分钟每 5 分钟相对成交量，`ink-300`，最后一根 `signal-orange`；不画价格迷你线（价格看涨跌列就够）。
- 停牌 / 无数据行整行 `ink-300`，涨跌列写状态字。

## 交互

- 点击行 → `symbol.set` 写入所选 LinkGroup；双击 → 打开 Desk；右键：加到其他列表 / 移除 / 下单 / 加监控 / 在 Lab 打开。
- 拖行排序（弹簧让位）；拖到分组行 = 改标签；从 Screener / PositionBook / 剪贴板拖入 = 加入。
- 粘贴一串代码（空格 / 逗号 / 换行分隔）= 批量加入，底部显示 `+12 · 2 未识别`。
- 排序：默认手动；一键切「异动」（命中时间倒序）、「涨跌」、「量比」。排序切换行重排 `snappy` ≤ 300ms。
- 键盘同 DataGrid；`/` 聚焦过滤框（代码 / 拼音首字母）。

## 规则

- 自选列表同步到账户配置（Query），行情经 MarketAPI；两条线不混。
- 涨跌只上数字；越整数位才闪。
- 一张列表 ≤ 200 行；更多的是筛选结果，不是自选。
- 不显示新闻、评级、情绪——那些在 NewsFeed。

## 谁提供什么

- 组件：lists[]、activeList、rows（含 held: accountCodes[]、alert: boolean、vol30[]）、linkGroup、onSelect、onReorder、onAdd。
