# YieldCurve

收益率曲线：期限（对数轴）× 收益率，多条叠加——今日、任一历史日（灰虚）、其它国家 / 曲线族（国开、AAA 信用、利率互换）。关键期限点标圆点，顶部 KPI 给关键利率与利差。PriceChart 多线皮肤的一个预设。

## 结构

- KPI 5 格：10Y · 2Y · 10Y−2Y · 10Y−1Y · 跨国利差；变化小字 bp。
- 图：期限对数轴（1M…30Y），今日曲线 `series-1` 2px + 关键期限圆点；历史对比 `ink-300` 虚线；其它曲线 `series-2..7`；无填充。
- 图例一行含来源（中债 / FRED / 自拟合）。
- 倒挂时 10Y−2Y KPI amber（不是红绿）。

## 交互

- 悬停期限 → tooltip：各曲线该期限值、与对比日差。
- 对比日选择（昨 / 一月前 / 一年前 / 自定义 / 事件日）；曲线族增删（≤ 7）。
- 「历史动画」：拖时间滑杆看曲线形状变化（`gentle` 过渡，无自动播放）。
- 点击期限点 → BondCalc 预填该期限基准。

## 规则

- 数据来源标注；拟合曲线（NSS）必须与原始点同时显示，标 run。
- 不做 3D 曲面（期限 × 时间 × 收益率）——用 Heatmap 顺序色代替。
- 不用涨跌色；利率上升不是"涨"。

## 谁提供什么

- 组件：curves[]（id、label、points[{tenor, yield}]、source、date）、keyTenors、spreads、onPickTenor。
- 调用方：数据平台（FRED / 中债 / AkShare）或拟合 run。
