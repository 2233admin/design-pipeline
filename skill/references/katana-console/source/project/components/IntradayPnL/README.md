# IntradayPnL

日内盈亏曲线：从开盘到现在，合计（`ink-100` 粗线）与各账户（`series-n` 细线）的盈亏路径，日亏损限额是一条红虚线。它是盯盘时唯一需要一直在屏上的盈亏图；readability §25 的规则在这里最严格——曲线涨跌没有任何反馈。

## 结构

- KPI 5 格：今日盈亏（含 % 与时间）· 日内最高 · 日内最低 · 日亏损限额（含离限额距离）· 已实现。只有今日 / 最低 / 已实现数字用 `pnl-*`。
- 图：时间轴按 Profile.calendar（午休、夜盘以 `bg-100` 竖带标出，不压缩）；零线 `line-200`；限额线 `signal-red` 虚线；末点橙。
- 图例一行：合计 + 账户短码；点击切换显示。
- 跨限额时：限额线变实、面板进入告警阶梯第 3 级（边框 amber + 中部大字"日亏损到限 · 交易锁由执行网关下发"），面板本身不发锁。

## 交互

- 悬停 → tooltip：时间、合计、各账户、当时持仓数；十字线跨 LinkGroup。
- 点击账户图例 → 只看该账户，限额线换成该账户限额。
- 右上三件：表格视图（分钟级）· 导出 · 加入报告。
- 周 / 月切换 → 变成 PnLLedger 的曲线视图（累计），限额换周 / 月限额。

## 规则

- 每分钟一个点（Pacer 节流）；不做每 tick 重绘。
- 曲线不填充面、不用涨跌色、无音效、无弹簧；新点 `snappy` 延伸仅此而已。
- 午休 / 夜盘不压缩时间轴——压缩会让盘中斜率失真。
- 研究账本不画。

## 谁提供什么

- 组件：series{total[], byAccount{}}、limits{day, byAccount}、session（Profile）、realized、onFocusAccount。
- 调用方：`book/aggregator` 分钟快照 + 限额（RiskBoard 同源）。
