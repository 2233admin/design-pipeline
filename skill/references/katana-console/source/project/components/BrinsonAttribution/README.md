# BrinsonAttribution

Brinson 归因：超额收益拆成配置（权重差 × 基准行业收益差）、选择（基准权重 × 收益差）、交互三效应，按行业（或风格 / 国家）一行三条零轴条，合计列用涨跌色数字。计算是 Lab 的 run（多期 Carino 链接），前端只显示。

## 结构

- 顶行：run 蓝标 · 方法与维度 · 区间 · 组合 vs 基准 · 右侧总超额 = 三项 LCD。
- 列：行业 · 组合权 · 基准权 · 配置条 · 选择条 · 交互条 · 合计。三条零轴条共用刻度（页脚写出），`ink-200` 纹理；合计数字 `pnl-*`。
- 按 |合计| 排序，Top 6 + `其他 ×n`；维度切换（行业 / 风格 / 国家）走 Segmented（在"切维度"里）。
- 零权重行（未持有的基准行业）配置条有、选择交互为零——这正是 Brinson 要说的事，不隐藏。

## 交互

- 点击行业行 → PositionBook 过滤该行业 + PnLAttribution 按品种显示该行业内部；再点取消。
- 悬停条 → tooltip：公式与数值（权重差、收益差）。
- 切区间 / 基准 → 新 run（RunLauncher 预填，秒级）。

## 规则

- 三效应颜色不区分（都是 `ink-200`），靠列区分；不做堆叠条。
- 基准构成来自数据平台；组合权重来自 `book/aggregator` 的日快照。
- 不做"归因饼图"。
- 研究账本可作为组合进来（Lab 用法）。

## 谁提供什么

- 组件：rows[]（group、wP、wB、alloc、select、inter、total）、totals、dim、run、onPick。
- 调用方：归因 run（Query）。
