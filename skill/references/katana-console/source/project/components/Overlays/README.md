# Overlays

浮层皮肤：Dialog、Popover / Select 列表、Menu（右键与下拉）、Tooltip。Base UI 提供焦点管理、Esc、层叠与无障碍；本系统定外观与"升起"动效。

## 共同规则

- 浮层 = `bg-400` + `hairline` + `shadow.lift` + `radius-md` 4px，从触发元素或面板**升起**（scale 0.96 → 1、y +8 → 0、`gentle`），下层 scale 0.985 + 亮度 -8%。关闭反向，120ms。
- 多层叠放每层只关一层（Esc 一次关最上层）。
- 不做毛玻璃背景、不做全屏遮罩变暗超过 40%。

## Dialog

- **L4 占屏确认**（告警阶梯第四级）：顶部 10px `hazard` 斜切条纹带 · 点阵标题 · 对象区 `bracket` · 关键数 `display-dense` · 三行事实**同时出现**（发生了什么 / 系统已做什么 / 用户还能做什么），只有当三项检查确实先后返回时才按真实时间更新；已知悉 ≠ 已解决，关闭告警不解除交易锁；不遮住仍获准的处置入口（平仓 / 撤单）。保护的是安全语义与关键操作关系，字号 / 对比度 / 语言可适配（engineering.md §4.3 §5）。

- 32px 标题栏，左侧状态 LED（确认 amber / 信息 off / 危险 red）；正文键值对用 `mono`；底部按钮栏 `bg-300`，主按钮在右。
- **交易确认框受"动作风险保护"**：任何 `sideEffect: write` 的流程里，关键对象、金额、方向、账户环境、权限提示、确认流程、结果状态不可被插件隐藏 / 改写 / 绕开；显示参数 hash，参数改动即失效；确认不配音效；实盘账户标题带"实盘"与 amber 边框。
- 回车 = 主按钮，Esc = 取消；焦点初始落在取消（防误按）。确认框故意降速：普通字体、普通字号、平淡语言、没有多余按钮（执行网络疲劳，§24）；文案每句 ≤ 12 字，先怎么办（§11）。

## Popover / Select 列表

- 行高 28，`mono`；当前项 `bg-000` + 左 2px orange；右侧快捷键 `ink-300` 10px（9px `ink-400` 不是文字）。菜单 ≤ 7 项，多了分组。
- 列表超过 8 项显示搜索输入（cmdk 风）；键盘 ↑↓ Enter。

## Menu（右键）

- 同 Popover，加分隔线；危险项红色文字放最后。
- 面板标题栏右键 = 换面板 / 联动组 / 固定 / 复制实例 / 关闭；表格行右键由面板提供。

## Tooltip

- 就是一个小 LCD 窗：`bg-000` + recess + `hairline`，`mono` 10px，`ink-200` 正文、`ink-100` 重点；延迟 300ms 出现，无动效；跟随指针的图表 tooltip 不延迟。
- 只放数据，不放操作。

## 谁提供什么

- 组件：Base UI 的标准 props；Dialog 额外 `tone`（info / confirm / danger）、`core`（true 时不可被主题替换）。
