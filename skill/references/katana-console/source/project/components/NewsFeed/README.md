# NewsFeed

新闻流：公告、新闻、RSS、数据源事件统一成一条时间流。每行：时间 · 来源 · 标题 · 关联品种 / 主题点阵标。持仓相关的行标题 `ink-100`、品种标橙，其余 `ink-200`。**不做情绪着色**——情绪分数是模型输出，不是事实，不进颜色（可在 tooltip 里看，标来源）。

## 结构

- 顶行：过滤 Segmented（全部 / 持仓 / 自选 / 公告 / 宏观）· 来源数 · 右侧未读数与自动滚动灯。
- 行 26px：时间 `ink-300` · 来源（交易所公告 `signal-blue`，其余 `ink-300`）· 标题 `sans` · 右侧品种 / 主题标 ≤ 3 个。
- 低可信来源（用户标记）整行 `ink-300`。
- Virtual 滚动；新条目从顶部进（SmartTape 规则：用户上翻则停，底部 `↓ 新 n`）。

## 交互

- 点击行 → 展开摘要（≤ 3 行）与原文链接；点击品种标 → LinkContext；双击 → 该票 Desk。
- 右键：加入笔记（Notes，带引用）· 屏蔽来源 · 建警报（AlertCenter：该品种公告即 L1）。
- `/` 搜索标题与品种。
- 公告类自动关联 CorporateActions（分红 / 送转公告直接生成事件）。

## 规则

- 来源可信度由用户标，不由模型判；模型摘要进 tooltip 并标 `AI 摘要 · 来源`。
- 不显示点赞、评论、热度。
- 保留 7 天在前端，更久走数据平台搜索。
- 中英混排标题用 `sans`，品种标用点阵。

## 谁提供什么

- 组件：items[]（ts、source、title、symbols[]、topics[]、kind、url、summary?、trust）、filter、held、watch、onOpen、onAction。
- 调用方：数据平台新闻 / 公告流 + RSS 适配器。
