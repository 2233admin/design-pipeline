# PnLLedger

盈亏总账：每个交易日每个账户（或策略 / 品种）的盈亏拆成四项——已实现、未实现变动、费税、股息利息——合成净盈亏，并与账户净值的期初期末差对账。PnLAttribution 回答"钱从哪来"，这里回答"每天记了什么账、账对不对"。

## 结构

- 顶行：维度 Segmented（按日 / 账户 / 策略 / 品种）· 区间与账户集合 · 右侧期初 → 期末 LCD、差额、对账灯（期末 − 期初 = Σ净盈亏 + 出入金 时 ok，否则 warn 并显示差额）。
- 列：日期 · 账户短码 · 说明（≤ 24 字符：几笔平仓、几个重估、特殊事件）· 已实现 · 未实现Δ · 费税 · 股息/利息 · 净盈亏。行高 `row-tight`。
- 每日合计行 `bg-300` + `ink-100`；休市日一行 `ink-300`（仍可能有利息）。
- 期货盯市重估标 `盯市` 点阵标；外币换算标 `估算`。
- 页脚：交易日数 · 四项月合计 · 导出 / 对账。

## 交互

- 点击一行 → FillLog 过滤该日该账户成交；点击"已实现" → TaxLots 显示该日平掉的批次；点击"未实现Δ" → PositionBook 切到"当日盈亏"列。
- 维度切换：按账户 = 行是账户 × 月合计；按策略 = 策略子账本；按品种 = 该区间每只票四项。
- 对账 warn → 展开差额来源候选（出入金未记 / 费率差 / 结算价未更新）。

## 规则

- 盈亏颜色只上数字；费税永远 `ink-100` 负数不着色（成本不是亏损）。
- 已实现按 Profile 的批次规则（FIFO / 加权，TaxLots 同源）。
- 研究账本不进总账。
- 账是 append-only：更正写冲销行，不改旧行。

## 谁提供什么

- 组件：entries[]（date、account、realized、unrealizedDelta、fees、income、net、memo、flags）、open、close、cashflows、dim、onDrill。
- 调用方：账户服务日结 + `book/aggregator`；对账计算在 Worker。
