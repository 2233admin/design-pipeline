# Heatmap

热力图。三种用途共用一个组件：行业 × 时间强弱（发散）、相关矩阵（发散，中点 0）、盘口 / DOM 历史热力（顺序 `seq`）。

## 结构

- 格间 1px `bg-100` 缝，无外框；行标签 `sans` 11px `ink-200`，列标签 `num-sm` `chart-axis`。
- 发散：负极 `div-neg` → 中点 `div-mid`（中性灰）→ 正极 `div-pos`，各 3 档；**全饱和只给极值（top 2%），大面积用 `-100/-200`**——整屏红放大焦虑（readability §14）；正负色跟随 Market Profile，色觉友好模式切橙/蓝。
- 顺序：`seq-100..600`，低值接近面板色。
- 格内数值 `num-sm`：对比度 ≥ 4.5:1 才写字，深格用 `ink-100`，浅格用 `bg-000`，中点格 `ink-300`；不足的格不写。
- 底部色阶条 + 标注约定。

## 交互

- 逐格 tooltip：行、列、值、样本。
- 点击格 → 写入 LinkContext（行业 / 标的 / 时间），同组 Desk 跟随。
- 悬停行/列标签 → 高亮整行/列。
- 选中格 2px `signal-orange` 内描边。

## 动效

- 数据更新：格色 120ms 过渡；新增列从右侧 `snappy` 滑入。
- 不做翻转、不做逐格入场。

## 规则

- 发散色阶的中点永远是灰，不是黄或白。
- 行超过 40 或列超过 120 时先聚合，不缩小格子到 < 16px。
- 相关矩阵只画下三角。

## 谁提供什么

- 组件：rows、cols、cells[{r,c,v}]、scale（diverging / sequential）、domain、onCellClick。
