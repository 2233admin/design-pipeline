# DataQuality

数据质量热力：行 = 字段，列 = 日期，格 = 问题数（缺失 / 异常值 / 复权不一致 / 停牌未标）。顺序色按密度，`seq-600` 只给最严重格；休市格 `bg-100`。质量作业（Great Expectations 一类）在数据平台跑，前端只显示并把问题指向受影响的 run。

## 结构

- 顶行：数据集 @ 版本 · 月份 · 问题类型 Segmented · 右侧问题率与阈值（超阈 amber）。
- 热力：字段 ≤ 12 行可见（更多滚动），日期一个月；格内数字 = 问题数（≥ 1 才写）。
- 底行：选中格的说明——日期 · 字段 · 数量 · 原因 · 受影响的下游数据集 / run · 建议动作（重跑 run 蓝标）。
- 持续性问题（整行都有，如 pe_ttm 的新股空值）用 `seq-200` 不升级——这是预期缺失。

## 交互

- 点击格 → 底行说明 + 样本表（≤ 20 行受影响的品种 / 值）。
- 点击受影响 run → RunInspector；「重跑」→ RunLauncher 预填。
- 月切换 ←→；字段搜索。
- 「标为预期」→ 该字段该类问题降为 `seq-200` 并记录理由（写命令，走确认——它改变后续告警）。

## 规则

- 阈值与规则来自数据平台配置；前端不定义"什么算异常"。
- 顺序色，不是发散色；休市不是问题。
- 一个格 ≤ 3 位数，更多显示 `999+`。
- 停牌标记来自 Profile flags，与"缺失"区分。

## 谁提供什么

- 组件：dataset、version、month、cells[]（date、field、count、kind、expected）、issues（选中格详情）、onPick、onMarkExpected。
- 调用方：数据平台质量作业结果（Query）。
