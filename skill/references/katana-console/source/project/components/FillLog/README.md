# FillLog

成交日志：今天所有账户成了什么，append-only。它和 SmartTape 共用滚动机制（新行从顶部进、自动滚动、用户上翻时停住），但记录的是**自己的**成交，所以多了账户、滑点、来源三列。

## 结构

- 列（固定）：时间（到 0.1s）· 账户短码 · 代码·名称 · 方向 · 成交价×量 · 金额 · 滑点 · 来源。行高 `row-tight`。
- 方向用订单流色 BUY `bid` / SELL `ask`，点阵大写；不用涨跌色。
- 同一张单的多笔成交默认折叠为一行（均价 × 总量 + `3 笔` 点阵标），点击展开。
- 滑点 = 成交价 − 委托价（方向调整后），对自己不利时 `signal-amber`，有利不着色。
- 来源：手动 · GO / 手动 · 梯子 / 策略名 / OpenAlice · run id；点击 run id 跳证据。
- 断线重连、日切、对账完成在流里插分隔行（点阵 `ink-400`，states.md 恢复规则）。
- 放弃 / 拒单 / 撤单也记一行（`ink-300`，价量 `— —`），日志必须完整。
- 页脚：单数 · 笔数 · 买卖金额 · 均滑点 · 导出 CSV。

## 交互

- 新成交：行从顶部升起（`snappy`）+ 左 2px 橙描边 3s；音效按来源：手动 `fill`（中性短音）、策略 / OpenAlice 无音效（研究不是奖励，readability §25）。
- 点击行写 LinkContext；双击打开当时的 Desk 并把 ReplayBar 定到该时间。
- 筛选：账户（跟 AccountRail）、方向、来源、品种。
- 用户上翻 → 停止自动滚动，底部出现 `↓ 新 3` 计数胶囊，点击回到最新。

## 规则

- 不显示盈亏——成交本身没有盈亏，盈亏在 PositionBook / PnLAttribution。
- 永不删行、永不改写历史行；对账差异用新行记录。
- 跨日只看今天；历史查询是研究功能，进 Lab 的 DataGrid。

## 谁提供什么

- 组件：fills[]（ts、account、symbol、side、price、qty、orderId、slip、source）、markers[]（分隔事件）。
- 调用方：执行网关成交流 + 对账事件。
