# QuantileLayers

因子分层累计收益。Q1…Q5（或 Q10）是**序数**，所以用顺序色阶 `seq-200..600` 暗→亮，而不是类别色——一眼看出是否单调。

## 结构

- 每层一条 2px 线，颜色按分层序号取 `seq` 色阶；Q5（最高）最亮。
- 多空差（Q5−Q1）作为点阵纹理面垫在下面，线尾直接标 Q5 / Q1。
- 0 线 `line-200`。
- 底部一行结论：单调性是否通过、多空年化、换手、样本。

## 交互

- 悬停一层 → 其余 40%；点击锁定。
- 十字线与同因子的 FactorIC 同步。
- 切换 5/10 分层在局部工具条；切换后颜色重新按序号分配（这是序数的例外：颜色跟序号，不跟实体）。

## 规则

- 分层数 > 10 不画线，改热力图。
- 多空线不单独上色，用 `ink-100` 细线或点阵面。
