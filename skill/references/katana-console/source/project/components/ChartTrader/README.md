# ChartTrader

图上交易：在 PriceChart 上画自己的挂单、持仓线、止盈止损，并允许拖动改价、点击右轴下单。全部用 lightweight-charts Primitives 在 canvas 上画，不进 React 树；每次拖动结束产生一个 `order.*` 命令。

## 画什么

| 线 | 样式 | 右轴标签 | 左侧标签 |
|---|---|---|---|
| 自己的挂单（**已确认**） | 1px 实线 `order-own` amber + 中点拖柄 | amber 实底 `B 2,000` | `BUY 2,000 @ 245.50 · v3 · 拖动改价 · ×` |
| **草稿 / 拖动中** | 1px 虚线 amber | 空心 `草稿 245.50` | 网关不知道这条线 |
| **已提交未确认** | 虚线 + 点阵流动纹理 | `提交中` | 命令已发，等网关回答；期间不可再拖 |
| 持仓均价 | 1px 实线 `ink-100` | `ink-100` 底 数量 | `持仓 3,000 @ 243.10 · 浮盈（数字 pnl 色）· 平` |
| 止盈 / 止损 | 1px 虚线 green / red，标签空心 | `TP 250.2` / `SL 240.6` | 悬停才显示 |
| 最新价 | 1px `poc` | `poc` 底 | — |
| 成交标记 | 三角 ▲▼ 8px，`bid` / `ask` | — | 悬停 tooltip |

- 买卖方向用订单流色，涨跌只在浮盈数字上。
- 多账户在同一张图：每条线标签前缀账户短码；AccountRail 过滤同样作用于图上的线。
- 线数预算：同屏自己的线 ≤ 8 条，超过折叠为右轴一个计数标签 `+3`。

## 交互

- **拖柄拖动 = 改价草稿**：跟手，松手吸附最小变动价 → 确认框（绑定账户、标的、方向、数量、价格、**订单版本**，提交的是确认时的快照）→ 提交中 → 网关回答：接受则实线移到新价；**拒绝则显式**：线回原价 + 标签 `拒绝 · 原因` 5s + `cmd-err`，不静默弹回。动画结束不是改单成功。拖出图区 = 撤单草稿；双击 = 撤单草稿。
- **右轴点击 = 在该价位挂单**：左键买、右键卖，数量用工具条当前档；需开启工具条「图上下单」拨杆（默认关，与梯子共用一个开关）。
- 括号单：工具条设 TP / SL 百分比或点数；新单成交后自动画出 TP / SL 两条线，可各自拖。
- 持仓线上「平」按钮 = 市价平该账户该品种，走确认。
- 快速模式规则同 DOMLadder：实盘每会话确认一次；永不跳过风控拒绝。
- 工具条：账户短码 + 种类 · 数量档 ≤ 4 · 括号设置；`bg-300` 浮板，左上角。

## 规则

- 命令来源标 `图上`，进 FillLog 来源列。
- 拖动时不触发十字线、不触发 LinkContext 写入。
- 回放模式（ReplayBar）下 ChartTrader 禁用，线以 `ink-400` 显示历史单，不可拖。
- 不做趋势线下单、不做"沿线追踪止损"这类花活。

## 谁提供什么

- 组件：chart（LWC 实例）、orders[]、positions[]、fills[]、account、bracket、onCommand。
- 调用方：OrderBlotter / PositionBook 共享的数据流；命令表。

## ATAS 对照补齐（2026-10-03，atas.md §2.1 / §2.7）

- 右轴右键 = Stop 单；OCO 组；Cancel Bids / Cancel Asks 侧向撤单命令；Route 选择；Auto Detection 模式。
- 括号单与自动保护单的配置来源统一为 ExitStrategy（Simple / Multi-Level / Breakeven / Trailing），拖动止损线即 `position.setStop`。
- 跨 `ChartSurface` 复用：同一份订单层可画到 PriceChart（LWC）与 flow 层 / 自研 Canvas。
- Cross-Trading：分析合约与执行合约可不同（ES → MES 等配对表在 markets.md），下单票显示"执行合约"。
