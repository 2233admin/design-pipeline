# LossLimits

亏损限额：按账户 / 策略 / 全局的日、周、月亏损限额与连亏限制，当前使用度、触发动作、状态。它是 RiskBoard 的"盈亏专用"视图：RiskBoard 看敞口与集中度，这里只看"亏到哪里停、停什么"。限额只读，动作由执行网关执行，面板只显示。

## 结构

- 顶行：周期 Segmented（日 / 周 / 月）· 限额来源与快照时间 · 本月触发次数。
- 列：对象（账户短码 / 策略名 + 点阵标 / 全局）· 限额 · 使用度条（< 80% `series-1`，80–100% amber，≥ 100% red）· 当前 · 触发动作（点阵标 + 阶梯级别：告警 L2 / 暂停信号 L3 / 锁开仓 · 锁交易 L4）· 状态文字（正常 / 接近 / 已触发 时间 + 结果）。
- 已触发行状态 red，但行底不变色。
- 页脚：条数 · 触发 / 接近计数 · "触发由执行网关执行" · 触发历史 · 申请调整。

## 交互

- 点击行 → IntradayPnL 聚焦该账户 / 策略，限额线对应。
- 「触发历史」→ DataGrid：时间、对象、限额、当时值、动作、解除时间。
- 「申请调整」→ 跳账户服务（外部）；前端不改限额。
- 接近 80% 时一次 `radar-ping` + 状态 amber；触发时 `alarm-low` + 执行网关下发的锁在 RiskBoard 底行与 AccountRail 灯同步显示。

## 规则

- 限额与 RiskBoard、IntradayPnL 限额线同源（账户服务）。
- 使用度 = 当前亏损 / 限额；盈利时为 0，不显示"负使用"。
- 策略级动作最高 L3（暂停信号）；锁交易只属于账户级。
- 解除触发也是账户服务的事，面板显示"已解除 时间 · 由谁"。

## 谁提供什么

- 组件：limits[]（scope、period、limit、current、usage、action、level、state、triggeredAt、releasedAt）、history[]、period、onFocus。
- 调用方：账户服务限额与触发事件（Query + 流）。
