# 游戏感：让机器活起来的八件事

93 张卡是零件。零件对了机器不一定像机器——游戏 UI 的"高级"来自零件之间的东西：舞台、重量、生命、光、声音、仪式、进程、取景。这一页把它们写成规格。全部作用在**壳层与输入反馈**上，不作用在数据与盈亏上（readability §25 不动）。

## 1. 舞台：镜头而不是切换

游戏里没有"页面替换"，只有镜头移动。KATANA 的五个 Workspace 排成一条**横向胶片**，切换 = 镜头横移（`gentle`，整屏 translateX），旧现场从边缘退出、新现场从另一边进入，用户知道自己在空间里的位置。

| 动作 | 镜头 |
|---|---|
| 切 Workspace | 横移到相邻格；跨多格时加速穿过中间格（不逐格停） |
| 面板最大化 | **推进**（dolly in）：目标面板 scale 到满，其余面板向外后退并降亮度 8%，像镜头靠近 |
| 打开检查器 / 确认框 | 浮层**升起**（已有），底层后退（scale 0.985）——纵深 |
| 进入回放 | 镜头"后拉"一点（整屏 scale 0.98 + 角括号 + 时间轴出现），退出反向 |
| 进入 Lab 的某个 run | 从 FactorLibrary 卡片原位放大成台面（shared-element），回去原位缩回 |

实现：外壳容器 `perspective: 1200px`；Workspace 胶片用 Motion `layout`（只对壳，不对 canvas 面板内容）；面板的 z 由焦点决定（焦点 `translateZ(0)`，其它 `translateZ(-12px)`，视觉上几乎看不出但 hover 切换时有纵深）。reduced-motion：全部退化为 120ms 淡入淡出。

## 2. 重量：输入有分量

游戏手感 = 每个输入都有即时、分层、可感的反馈。KATANA 的三件套（动效 + 音 + 灯）只给**你的动作**，不给**市场结果**。

| 输入 | 视觉 | 声 | 灯 |
|---|---|---|---|
| 按钮按下 | 2px 下沉 + 顶部高光消失（像真按键）；松开 `snappy` 回弹 | `key-down` 短 / `key-up` 更短更高 | — |
| 拨杆 | 滑块跟手，越过中点"咔"，落位 2px 过冲 | `toggle-click` 塑料 | 对应 LED |
| 分割线吸附 | 1px 脉冲 | `snap` tick | — |
| 拖起面板 | scale 1.02 + 抬高阴影 + **2° 轻微倾斜（跟拖动方向）**；松手 `settle` 落下，阴影收回 | 抬起 `lift` 低频；落下 `drop` 闷响 | — |
| 命令执行 | GO Bar 闪一次橙 + 命令回显打字机 60ms | `cmd-ok` | — |
| 切 Workspace | 胶片横移 + 新 Workspace 名用 `display-dense` 从 1.1 缩到 1.0 出现 400ms | `tab-slide` | — |
| 进入实盘账户 | amber 框**从四边滑入合拢** 240ms；不是淡入 | 重的双击 `latch` | 账户灯 amber |
| 提交 → 确认 | 确认框升起；按钮**无**重量感（故意，§24） | 无 | — |

硬规则不变：盈亏、价格、成交结果没有任何重量反馈；`bouncy` 只给研究产物。

## 3. 生命：机器在呼吸

空闲时机器要像开着的机器，不是截图。但生命只在**无人操作 60s 后**且**不在 Desk / 交易台面**出现（盯盘时屏幕必须静）。

| 空闲动效 | 周期 | 位置 |
|---|---|---|
| StatusBar 时钟冒号 BLED 瞬闪 | 1s | 任何时候（已有） |
| LED 矩阵"自检扫描"一行亮过 | 30s 一次 | 总览大屏 / 运行中心 |
| SystemHealth 波形带持续流动 | 连续 | 运行中心 |
| 开盘前倒计时 `display-dense` 翻页 | 1s | 总览 09:15–09:30 |
| hex 灯阵板块热度缓慢重排 | 数据驱动 | 总览 |
| 空面板的点阵占位符"信号雪花" | 连续低频 | 空态（states.md），只在 Lab |

生命动效全部 ≤ 2% 亮度变化或单个元素；安静模式与 reduced-motion 下全关。

## 4. 光：一个光源

游戏材质好看是因为光照一致。KATANA 定**一个光源：左上 45°**，所有材质服从它：
- `plate` 上高光 / 下阴影（已有）；`recess` 顶部内阴影最深（光来自上方照不到凹槽顶）；LED 高光点在左上（`inset 0 0 2px rgba(255,255,255,.4)` 改为左上偏移 `inset -1px -1px 2px`）。
- **焦点面板 rim light**：1px 顶边 + 左边高光 `rgba(255,255,255,.08)`，其它面板没有——这是"这块被照到"。
- hover 的材质反应：面板标题栏亮度 +3%（像手电扫过），不是变色。
- Paper 主题同一光源，高光更亮、阴影更浅。
- 不做动态光源、不做鼠标跟随的高光（那是装饰）。

## 5. 声音：有空间、有层

- **声像跟位置**：面板发出的声音按它在屏幕上的横向位置做立体声 pan（左 1/3 面板 → L 0.4，右 1/3 → R 0.4）。这是游戏最便宜也最有效的"空间感"技巧，Howler `stereo()` 一行。
- **三层**：UI 层（按键、拨杆、吸附，短促干燥）· 机器层（link-up / down、latch、lift / drop，低频有体）· 事件层（ping、alarm、run-done，有音调）。每层独立音量（Preferences 声音节）。
- **可选环境底噪**：机房风扇 −36dB 粉噪，默认关；开着时开盘自检与收盘摘要时短暂抬到 −30dB 再回落（仪式感）。
- 每个音有 transient + body + 短尾，不用纯合成 beep；文件由人提供（blueprint §7）。

## 6. 仪式：开机、开盘、收盘、结算

已有开盘自检；补齐一天的四个仪式，全部在 3 秒内、全部可关：
1. **开机**：Cover 的 LED 矩阵逐行点亮 `KATANA · QUOTE · EXEC · ALICE`，StatusBar 段从左到右依次就位（stagger 40ms），时钟最后亮。
2. **开盘自检**（已有）：09:28 全屏 Workbench LED，`link-up`。
3. **收盘摘要**：15:05 从底部升起一张"结算卡"——不是盈亏庆祝：今日 PnLLedger 合计（数字直接显示不滚动）、成交数、命中数、待决事项数、明日公司行动；3s 后收回或点开进 Cockpit。`run-done` 不响（这是账，不是研究产物）；用一声中性的 `latch`。
4. **研究结算**：run 完成 = 唯一允许 `bouncy` 的时刻（已有）。

## 7. 进程：看得见的推进

游戏让人上头的是进度可见。KATANA 的进度全是真实业务进程，不造虚假进度：
- DeploymentBoard = 策略的"科技树"：research → paper → live 四列，门是**插槽**：五个凹槽，过一道填一格（点阵纹理填充 `snappy`），门全满卡片边缘亮一圈 rim light 1s——这是推进资格达成，不是盈亏。
- RobustnessGate 十格同理：评估完成逐格落定。
- paper 第 n / 60 日的同步率条每天长一格（Meter `sync`）。
- RunQueue 的进度 Meter 真进度；无自报进度的用点阵流动纹理（不假装百分比）。
- 不做：经验值、等级、成就、连胜。

## 8. 取景：HUD 框住当前对象

- Desk 顶部的当前品种用**取景框**：切品种时四个角括号从外侧 8px 收拢到位（`snappy`，120ms），像锁定目标；锁定后括号静止。一屏只有这一组括号（signature.md 预算）。
- 大数用 `display-dense`：Workspace 名、Cockpit 的 Capital 数、确认框的数量 / 金额。
- 面板标题栏左侧的 LinkGroup 色标在联动触发时"闪一次"（亮度脉冲 80ms），让人看到联动在哪些面板之间传播。

## 9. 不做（游戏里有、这里没有的）

屏幕震动、hit-stop、粒子、拖尾、故障艺术、数字滚动在价格上、音效在行情上、成就与等级、随机奖励、任何让盈亏"好玩"的东西。游戏感来自**操作一台好机器**，不是来自赌场。

## 10. 参考（学什么，不学什么）

| 作品 | 学 | 不学 |
|---|---|---|
| Elite Dangerous 驾驶舱 | 橙色全息 HUD 的信息密度与取景框、面板随视线的轻微纵深 | 全息透明感（我们是实体机器） |
| NieR:Automata 系统界面 | 单色 + 数据表 + 机器音效的克制、菜单的"硬件感"过渡 | 噪点与故障 |
| Death Stranding 的 diegetic UI | UI 是世界里的物件（我们的 LCD / LED 就是） | 过度动画时长 |
| Persona 5 | 切场景时大字排版的戏剧性（Workspace 名 `display-dense`） | 倾斜与杂志拼贴 |
| Hades | 输入反馈的层次与节奏（按键 / 拨杆 / 落位） | 战斗 juice |
| Factorio / Satisfactory | "工厂在运转"的生命感（空闲动效、机器层声音、低噪） | 复杂度 |
| Alien: Isolation | CRT 终端的材质与开机仪式 | 曲率、强闪烁 |
| Into the Breach / Mini Metro | 极少动效却很"活"：每个动效都承载信息 | — |

## 11. 实现与验收

- 游戏感的参数全部进 `motion.tokens.json`（弹簧、倾斜角、rim light 强度、声像宽度、空闲周期）与 `sound.md` 清单；Preferences 动效节暴露"完整 / 克制 / 关"三档，不暴露单项。
- 样机 A（engineering.md §9）加一组"壳层手感"检查：开机、切 Workspace、拖面板、最大化、进回放、进实盘、空闲 60s；每项在 reduced-motion 下功能一致。
- 验收是人坐在真实面板前的判断 + 帧时 p95（任何仪式不得让帧时 > 12ms）。
