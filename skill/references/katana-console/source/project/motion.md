# 动效与手势

Apple 式交互的四条规则，落成可以写进代码的参数。所有数值是首版基线，由人在真实面板上调整后写回。

## 1. 弹簧而不是缓动曲线

一切位移、缩放、展开/收起、拨杆切换用物理弹簧（Motion `spring`），不用 `duration + easing`。CSS `transition` 只允许用在颜色与透明度上（120ms linear）。

| 预设 | stiffness | damping | mass | 用在 |
|---|---|---|---|---|
| `snappy` | 520 | 38 | 0.8 | 拨杆、按钮按下、标签切换、LED 点亮 |
| `gentle` | 260 | 30 | 1 | 面板最大化/还原、侧栏滑出、sheet 升起、分割线复位 |
| `bouncy` | 340 | 18 | 1 | 回测完成、门通过——允许过冲一次的"结算感"。**只给研究产出，永远不给成交与盈亏**（见 readability.md §25） |
| `settle` | 180 | 28 | 1 | 拖拽松手后的落位、橡皮筋回弹 |

所有弹簧 `restDelta: 0.5px`。

## 2. 可打断、可接管

动画中途再操作，从当前位置和当前速度续，不等播完、不跳帧。实现：Motion 的 `animate` 默认可打断；禁止用 `onAnimationEnd` 串逻辑；状态由状态机决定，动画只是状态的投影。

## 3. 直接操控与橡皮筋

- **拖拽跟手**：拖的东西必须贴着指针/手指，零延迟，用 `transform` 不用 `top/left`。
- **越界橡皮筋**：超过边界 `d` 像素时实际位移 = `d × 0.55 / (1 + d / 220)`（上限约 120px）。分割线拖过最小尺寸、列表拉到头、拨杆拖过槽端都用这条。
- **松手投影**：落点 = 当前位置 + 速度 × 0.18s，再吸附到最近的合法位置（拨杆的两端、分割线的吸附点），用 `settle` 弹回。
- **吸附阈值**：分割线靠近 1/2、1/3、2/3 时 6px 内吸附；拨杆超过 40% 行程即视为切换。

## 4. 层级靠纵深

弹出层不是"出现"，是从面板上**升起**：从 scale 0.96 / opacity 0 / y +8px 用 `gentle` 到位；下层同时 scale 0.985、亮度降 8%。关闭反向。拖起一个面板：scale 1.02 + `shadow.lift`。

## 5. 时长上限

任何单次动效的视觉时长不超过 400ms（弹簧的 settle 时间）。超过说明刚度太低或用错预设。

## 5b. 什么时候不许动

动效边界表见 engineering.md §5：Splitter 拖动无弹簧、Toggle 落位 ≠ 生效、面板交换不重建实例、确认框不逐行表演、L4 三行同时出现、可执行数字不插值、含 canvas 的面板不用 `layout`、Howler 未解锁时界面自足。参数管线：滑杆 → 导出候选 → 三场景验证 → 审阅 → 写入 `motion.tokens.json`（代码唯一来源）→ 同步本页理由。

## 6. 安静模式与 reduced-motion

- `prefers-reduced-motion: reduce` 或用户开启 QUIET：所有弹簧退化为 120ms linear 的 opacity/transform；橡皮筋关闭；LED 不闪只变色。
- 盯盘态默认不播放 `bouncy`。

## 7. 什么不动

- 行情数字本身不做滚动动画（高频下会糊），只在 LCDReadout 这类低频读数上做数字滚动。
- 表格行不做进入/离开动画。
- 背景、边框、网格永远静止。

## 实现约定

- 动效参数唯一来源 `src/ui/motion/motion.tokens.json`（版本化）；`motion.ts` 读它导出四个 spring 预设、rubberBand()、project()。本页写目的、适用状态、禁用条件、reduced-motion 规则，不另维护一份数值。
- 组件只引用预设名，不写数字。
- Claude Code 实现时只留接口与保守默认，PR 必须列出"待人工调整"的参数。
