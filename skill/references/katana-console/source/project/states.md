# 状态：空 · 加载 · 错误 · 断线 · 过期

每个面板和表格都有这五种"非正常"状态。规则：**表头和外框保留，状态只占内容区；永远说清三件事——发生了什么、影响什么、能做什么。** 不弹 toast 代替，不用裸报错。

## 五态

| 状态 | 视觉 | 文案结构 | LED |
|---|---|---|---|
| **空** | 内容区居中：点阵标签 + 一行说明 + 一个动作 | "还没有自选 · 从筛选结果或命令行加入"（动作：加入） | off |
| **加载** | 骨架：行高按密度画 `bg-200` 条（点阵纹理，`line-200`），不转圈 | 顶部 `caption`："加载 持仓 · 账户 A" | on（orange，呼吸关） |
| **错误** | 内容区保留上次数据（变 `ink-400`）+ 顶部 amber 条 | "回测 2c91 失败 · 数据缺口 2025-03 · 查看证据 / 重试" | warn |
| **断线** | 顶部 red 条 + 数据冻结（最后一笔时间显示）+ 自动重连倒计时 | "行情断线 14:32:10 · 重连中 3s · 数据冻结于 14:32:09" | danger |
| **过期 / 估算** | 数据保留，右上角 amber 角标 `STALE 02:14` 或 `估算` | 悬停说明来源与时间 | warn |

## 加载骨架规则

- 骨架行数 = 面板可见行数；表头真实渲染。
- 超过 2s 显示"仍在加载 · 来源 X"；超过 10s 变错误态并给重试。
- 图表骨架：网格 + 轴，不画假线。

## 错误文案

- 每句 ≤ 12 字，先怎么办再为什么（压力下阅读理解下降 30–40%）。
- 写需要什么 / 发生了什么 + 怎么办，不写操作失败。
- 带 run id / 任务 id / 时间，点击可跳证据。
- 不用感叹号，不道歉。

## 数据语义

- 未知显示 `— —`（`ink-300`），**不显示 0**。
- 估算值（如无逐笔方向时的买卖推断）必须带 `估算` 角标。
- 已完成的研究结果永远不会"过期"，只会被新运行取代。

## 告警升级阶梯（readability §12 §26）

每级都比上一级稀有；同类合并计数，不逐条堆：

1. 一次 `radar-ping` + 点阵灯亮（周边可见：亮度，不靠颜色）
2. 持续 LED（不闪）
3. 面板边框 amber + 信息进入面板中部大字（压力下隧道视野）
4. 占屏确认，只给账户 / 执行类；怎么办按钮在注视点旁

20 分钟内同级 > 5 次自动降级合并为计数。

## 反馈三件套

- 断线：`link-down` 音效 + LED red + 面板边框不变（边框只给交易锁）。
- 恢复：`link-up` + LED green + 新数据前插分隔行。
- 错误：无音效（研究类）/ `alarm-low`（交易类）。

## 规格层状态词表（spec.md §3）

规格包定义的 `loading / live / stale / gap / resyncing / replay / unsupported / degraded / disconnected / error` 与本页五态的对照在 spec.md §3；本页新增态的视觉：

| 状态 | 视觉 | 文案 |
|---|---|---|
| **gap（序列缺口）** | 簿 / 格矩阵冻结显示（`ink-400`），顶部 amber 条，派生区（失衡 / Pulling / 热力新列）停更并留空带，不插值 | "序列缺口 seq 100→102 · 已停算失衡 · 等待快照" |
| **resyncing（重建中）** | 同上 + LED on 呼吸关；快照到达后原子替换，插一条分隔行 | "重建订单簿 · 快照 #4821" |
| **unsupported（不适用）** | 空态变体：点阵标签 + 原因，不显示 0 | "不适用 · Provider 不提供 L2" |
| **FIXTURE / PAPER / REPLAY / SHADOW** | 永久可见的点阵标（不只用颜色），与 LIVE 灯互斥；FIXTURE 为样机专用 | — |

规则重申：`0 ≠ null ≠ unsupported ≠ stale ≠ not yet loaded`；账户事实过期与市场价格过期是两个维度（Qty 仍显示，Mark / PnL 标 stale）；每个状态必须可独立注入测试。
