# 量化数据可视化

量化工作台 70% 的面积是图。这一页定图表的词汇表：每种研究产物对应哪种图、颜色怎么分配、标记怎么画、怎么交互、怎么动。

## 1. 图表清单（按研究产物）

| 研究产物 | 图 | 组件 | 色 |

## 2. 颜色的四种工作

| 工作 | 规则 | token |
|---|---|---|
| **类别**（哪条策略、哪个因子） | 固定顺序分配，永不循环；第 8 个折进「其他」；筛选后幸存者不重新上色 | `series-1..7`, `series-other` |
| **大小**（热度、成交量、分层序号） | 单色橙，暗→亮；深色模式下低值接近面板色 | `seq-100..600` |
| **正负**（收益、IC、相关系数） | 两极 + 中性灰中点；两极必须有明度差 | `div-neg / div-mid / div-pos`，CVD 安全模式切 `-safe` |
| **状态**（门通过、受锁、断线） | 只用信号色，带图标与文字，不单靠颜色 | `signal-*` |

三条硬规则：
- 序列色（`series-*`）比信号色（`signal-*`）暗一档，专给图表线面，已通过色觉校验（深色面 `bg-300` / `bg-000` 上 L 0.48–0.67，相邻 ΔE ≥ 9.8）。信号色只给 LED、文字和强调，不进图表序列。
- 涨跌约定来自 Market Profile（默认国际绿涨红跌，`cn` 红涨绿跌，`cvd` 橙/蓝），组件只写 `pnl-up / pnl-down`；红绿是色觉最差的一对，所以两者**必须**有明度差，且「色觉友好」开关全局切到橙/蓝。
- 基准线永远灰。有颜色的线只能是用户的东西。
- 大面积（热力、面）只用低饱和档，全饱和只给极值；涨跌色不上面积（readability §14）。
- 量用长度（条）不用颜色深浅；热度、成交量映射用对数（§19）。

## 3. 标记规范（工业版）

- 线 2px；基准线 1px 虚线；多于 4 条线时非焦点线降到 40% 透明。
- 柱：瘦柱，柱间 2px 面板色间隙，顶端 2px 圆角，底部贴基线。IC 柱这种正负柱不圆角。
- 热力格：格间 1px `bg-100` 缝，格内数值用 `num-sm` + `ink-100`，低于 4.5:1 的格不写字。
- 面：回撤、分层带用 **点阵纹理填充**（4px 实 2px 空，同 Meter）而不是实色透明——这是本系统图表的签名。
- 标记点 ≥ 8px；最后一个点、最优点、当前点用 `signal-orange` + glow。
- 网格 `chart-grid`，比分隔线更暗；轴文字 `chart-axis` `num-sm`；图表没有外边框，靠 PanelFrame。
- 直接标签：≤ 4 条线在线尾直接标名，更多用图例；数值不满屏标，只标端点与极值。
- 文字永远用 ink token，不用序列色。

## 4. 交互（和 motion.md 一致）

- 折线/面积默认带十字线 + tooltip；柱/点/格默认带逐标记 tooltip。tooltip 是一个 LCD 窗（`bg-000` + recess），数值 `num`。
- 十字线跨同一 LinkGroup 的所有图表同步（时间对齐）。
- 刷选（brush）一段时间 → 该段成为 LinkContext.range，同组图表和研究工具跟随；已完成的研究结果不跟随。
- 悬停一条线 → 其他线降到 40%，图例对应项高亮；点击锁定。
- 缩放：滚轮 = 时间缩放，Shift + 滚轮 = 价格缩放；双击复位；有橡皮筋。
- 每张图右上角三个图标：表格视图、导出 CSV、全屏。表格视图是无障碍兜底，必须有。

## 5. 动效

- 新数据到达：折线末端用 `snappy` 延伸，不整条重绘；高频（> 2Hz）直接赋值。
- 切换序列 / 筛选：进出的线用 opacity 120ms；留下的线**不重新上色、不重新定位**。
- 回测结果首次出现：净值线从左到右 300ms 画出（`gentle`），回撤面随后升起，结算时最后一点 `bouncy` 一次 + `run-done`。
- 热力图数据更新：格子颜色 120ms 过渡，不做翻转。
- 安静模式：以上全部退化为直接赋值。

## 6. 技术路线

- K 线、净值、IC、分层、散点：lightweight-charts（Custom Series / Primitives）或 自研 Canvas 2D；两者共用同一套 tokens 与 tooltip 组件。
- 热力图、Footprint、DOM 历史、成交量轮廓：自研 Canvas 2D，列式数据，rAF 合并绘制；WebGPU 作为后端选项。
- 所有图表读 `tokens.css` 的变量，不内置颜色；图表组件接收 `theme` 对象（由 tokens 生成）而不是自己 `getComputedStyle`。
- 每种图一个 Storybook story，覆盖：空数据、单序列、7 序列、超出 7、负值、NaN 缺口、色觉友好开关。
