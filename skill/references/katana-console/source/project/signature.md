# 控制室签名元素

工业控制台再往前一步：九十年代动画里那种**指挥中心**的视觉语言——黑橙高对比、斜切面板、警示条纹、六角格、角括号、密排大字、三方表决、同步率条、扫描线。这些元素让系统有"机器在运转、有人在值班"的紧张感，但每一个都有预算：它们是**壳层与关键时刻**的词汇，不是面板内容的日常。

拿的是视觉词汇，不拿任何作品的标志、名称、角色、原画或配色方案；颜色全部仍是我们的 token。

## 1. 元素清单

| 元素 | 是什么 | 允许出现 | 不允许 |
|---|---|---|---|
| **斜切** `chamfer` | 面板 / 块的一角或两角 45° 切 8px（`clip-path`） | 顶栏、底栏、占屏确认框、大屏标题块、ConsensusBlock | 普通 PanelFrame、表格单元、按钮 |
| **角括号** `bracket` | 四角 1px L 形短线（10px），标出"当前对象" | 大屏模式的焦点面板、占屏确认的对象区、ReplayBar 定位到的时刻 | 同屏 > 1 组；普通选中态（那是左 2px 橙） |
| **警示条纹** `hazard` | 45° amber / `bg-000` 条纹带，8px 周期 | 告警阶梯 **L4** 的顶部带、交易锁状态行、实盘账户确认框标题栏边 | 任何 L1–L3；装饰 |
| **六角格** `hex` | 六边形单元代替圆点的 LED 矿阵 | 异动灯阵（宇宙 / 板块）、策略容量使用、门矩阵 | 表格内、小于 10px 的格 |
| **扫描线** `scanline` | 2% 亮度的 2px 横纹叠层 | 大屏模式整屏、开盘自检 3 秒、ReplayBar 回放中（提示"这不是实时"） | 普通工作区；对比度低于 4.5:1 的文字之上 |
| **密排大字** `display-dense` | Barlow Condensed 800 大数 + 9px 点阵标签紧贴，行高 0.9 | 大屏 KPI、占屏确认的关键数（数量 / 金额）、开盘自检 | 表格、面板标题 |
| **三方表决** ConsensusBlock | 三格并列各一盏灯 + 一行结论；三方 = 执行网关预检 · 账户服务限额 · 规则引擎 | OrderTicket / OrderBasket 提交前、DeploymentBoard 推进确认、L4 占屏 | 研究类命令（无表决） |
| **同步率条** `sync` | 带刻度齿的分段条 + 右侧大百分比 | paper 天数进度、容量使用、偏离门距离、回放进度 | 普通 Meter 场景 |
| **波形带** `wave` | 1px 折线心电式连续波形，右进左出 | SystemHealth 延迟 / 帧时、DataSources 行展开、顶栏 QUOTE 旁 24px 迷你 | 任何盈亏或价格序列 |
| **序列点亮** | 逐行点亮的文字（已有：开盘自检） | 开盘自检、L4 占屏出现时三行事实逐行亮 | 其它 |

## 2. 预算（叠加在 readability.md 之上）

- 一个面板内 ≤ 1 个签名元素（ConsensusBlock 自带斜切与灯，算 1 个）。
- 一屏 ≤ 1 组角括号、≤ 1 条警示带；扫描线只在大屏 / 自检 / 回放三种整屏状态。
- 签名元素不发光（发光体预算仍只给 LED / 拨杆 / 指针）；条纹不动、括号不动、斜切不动。
- 安静模式：扫描线关、条纹保留（它是语义）、斜切与括号保留（它们是形状）。
- 中文 / 英文只用现有字体角色；不引入日文、假名或任何第三种文字做装饰。

## 3. 和既有组件的关系

| 组件 | 吸收的元素 |
|---|---|
| PanelFrame | 大屏模式下焦点面板加角括号；壳层（顶栏 / 底栏）斜切 |
| StatusLED | 矿阵新增 `hex` 形态；门矩阵默认 hex |
| Meter | 新增 `sync` 形态 |
| DotMatrix | 展示全部签名元素的标本页 |
| Overlays · Dialog（L4） | 顶部警示带 + 对象区角括号 + 密排大字 + 三行序列点亮；核心界面，不可皮肤化 |
| OrderTicket / OrderBasket | 预检灯行升级为 ConsensusBlock |
| DeploymentBoard | 推进确认框用 ConsensusBlock（门 · 容量 · 账户） |
| ReplayBar | 回放中整屏扫描线 + 时刻角括号 |
| SystemHealth / DataSources | 波形带 |
| 总览（大屏） | 密排大字 KPI、扫描线、hex 异动灯阵 |

## 4. Token

`border.chamfer-8`（clip-path 多边形）· `border.bracket`（四角 L 形的 background-image 配方）· `shadow.hazard`（条纹 background-image）· `shadow.scanline`（横纹叠层）· `type.display-dense`（Barlow Condensed 800 / 行高 0.9 / 字距 -0.01em）。全部在 tokens.json；组件只引用。

## 5. 不做

- 不做旋转的瞄准环、雷达扫描动画、"HUD 悬浮"。
- 不做故障艺术（glitch）、色差（chromatic aberration）、噪点。
- 不做斜体字、倾斜整个面板。
- 不在数据区域叠任何纹理。
