# 音效与反馈三件套

重要事件 = **微动效 + 短音效 + 指示灯变化**。音效是"硬件感"的一半，几乎所有工具都没有。全部可关、分类可调。

## 音色方向

机械与电子混合：拨杆是真实的塑料"咔哒"，LED 点亮是极短的电子"滴"，警报是低频脉冲而不是尖叫。所有音效 ≤ 300ms，单声道，-14 LUFS 左右，不堆混响。文件：`assets/sounds/`（OGG + MP3 各一份），用 Howler.js 预加载。

## 清单

| 事件 | 音效 | 动效 | 指示灯 | 类别 |
|---|---|---|---|---|
| 拨杆切换到位 | `toggle-click` 塑料咔哒 | 滑块 `snappy` 落位 + 2px 回弹 | 对应 LED on/off | UI |
| 按钮按下 / 松开 | `key-down` / `key-up` 短促 | scale 0.97 → 1 | — | UI |
| 标签切换 | `tab-slide` 轻滑 | 下划线 `snappy` 滑移 | — | UI |
| 面板最大化 / 还原 | `panel-expand` 气动 | `gentle` 缩放 | — | UI |
| 分割线吸附 | `snap` 极短 tick | 1px 脉冲 | — | UI |
| 命令执行成功 | `cmd-ok` 双音上行 | 命令行闪一次 orange | — | UI |
| 命令失败 | `cmd-err` 双音下行 | 命令行抖 2px | — | UI |
| 行情连接 / 断开 | `link-up` / `link-down` | — | QUOTE LED green / off | 系统 |
| 异动命中 | `radar-ping` 短 ping | 异动面板对应灯 `snappy` 点亮 | 点阵灯 on | 市场 |
| 订单已提交 | `order-sent` 单音 | 订单条目淡入 | — | 交易 |
| 成交 | `fill` 中性实心"咚"，盈亏同音 | 持仓行 120ms 淡入，无弹跳 | — | 交易 |
| 账户 / 执行异常 | `alarm-low` 低频两拍 | 相关面板边框 amber | warn LED | 交易 |
| 回测完成 | `run-done` 三音结算 | 结果卡 `bouncy` 升起 | — | 研究 |
| 因子门通过 / 未过 | `gate-pass` 上行 / `gate-fail` 平 | 对应门 LED 点亮 | ok / warn | 研究 |

## 规则

- **冷却**：同一音效 400ms 内不重复；异动 ping 每秒最多 2 次。
- **优先级**：交易 > 系统 > 研究 > 市场 > UI；高优先级播放时低优先级静音。
- **分类音量**：UI / 市场 / 研究 / 交易 / 系统五个滑块 + 总开关；默认 UI 40%，交易 80%。
- **安静模式**：只保留交易和系统两类，其余静音；动效退化见 motion.md。
- **交易确认不配音效**。确认是人在做决定，不是机器在反馈。
- **盈亏不配奖赏式反馈**：盈利与亏损用同一音效、同一动效；`run-done` 这类三音结算只给研究产出。奖赏预测误差会训练用户追声音（readability.md §25）。

## 实现约定

- `src/ui/sound.ts` 导出 `play(id)`，内部做预加载、冷却、分类音量、优先级。
- 组件不直接 import Howler，只调 `play('toggle-click')`。
- 事件 → 音效的映射表放在 `src/ui/feedback.ts`，和动效映射放一起，状态机驱动。
- 音效文件由人提供或采购；没有文件前 `play()` 静默，不报错。
