# Text Message Video Skills

> Text-message animation skills for AI coding agents — turn a chat script into a scroll-stopping iMessage/WhatsApp/SMS conversation video, rendered from a messages array.

![Text Message Video Skills — animated showcase](./showcase.gif)

## Install

```bash
npx skills add iart-ai/text-message-video-skills
```

Or add it as a Claude Code plugin marketplace:

```bash
/plugin marketplace add iart-ai/text-message-video-skills
```

then `/plugin install text-message-video-skills`.

The skills run in Claude Code, Cursor, Codex, and 40+ agents. The full agent runs at **[iart.ai](https://iart.ai/?utm_source=github&utm_medium=readme&utm_campaign=text-message-video-skills&utm_content=funnel)**.

## What's included

| Skill | What it does |
|-------|--------------|
| [text-message-animation](./skills/text-message-animation) | Animate a chat conversation — bubbles pop in one at a time, typing indicators pulse, sounds land on send, the thread auto-scrolls — across iMessage/WhatsApp/SMS, rendered from a script or CSV so one template prints endless videos. |

*Want these as editable, on-brand videos at scale — swap the script, lock the look, batch hundreds from a CSV? [iart.ai](https://iart.ai/?utm_source=github&utm_medium=readme&utm_campaign=text-message-video-skills&utm_content=link) is the AI motion agent that does that from a prompt or data.*

- "Make a fake text message video" or "animate an iMessage conversation."
- "Create a text story video," "WhatsApp/SMS conversation video," or "chat reply animation."
- "Typing indicator animation" or "render a chat thread to a video."
- "Batch text-message videos from a script/CSV."

## Example prompts

- "Turn this script into an iMessage story video with typing dots and read receipts."
- "Animate a WhatsApp conversation, one bubble at a time, with a pop on each send."
- "Batch-render 20 fake-text videos from this CSV of conversations."
