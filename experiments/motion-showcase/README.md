# Motion Studies

A directly viewable HTML animation showcase: orbital sculpture, kinetic typography, and a
scroll-revealed poster with mouse-responsive depth. No build or dependency installation needed.

Open `index.html` in a browser, or run:

```sh
node experiments/motion-showcase/server.cjs
```

Then visit http://127.0.0.1:4173. The preview server binds only to loopback.
Use the top-right pause button to freeze the compositions. OS reduced-motion preference is
respected automatically. Visual decisions and motion language live in DESIGN.md and MOTION.md.
