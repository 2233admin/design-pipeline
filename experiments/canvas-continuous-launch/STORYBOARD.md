# Connected imagination — 22 seconds

Benefit: an idea, its reference and the resulting compositions remain connected in one creative
workspace. The viewer watches that connection happen. Grammar: continuous transformation with
motivated camera movement. Asset truth: a concept demonstration using the original generated
landscape from the previous experiment; storyboard panels are crops, not generated videos.

| Time | Product action | Focal object / before → after | Camera | Handoff | Rhythm |
| --- | --- | --- | --- | --- | --- |
| 0–3.8 | Enter an idea | Character seed → typing cursor inside prompt | Pull back to expose the node | Cursor reaches output port | Quiet then gathering pace |
| 3.8–6.7 | Connect prompt to image | Output port → signal → image border | Track the signal right | Signal deposits image glyphs | Acceleration |
| 6.7–10.8 | Resolve the image | Displaced ASCII samples → image structure → color | Push into the same image | Same mountain silhouette survives | Assembly then color release |

| 12.8–17.5 | Organize a storyboard | Image → three connected compositions; prompt moves above | Pull back to expose relationships | Cards contract toward their shared center | Expansion / settle |
| 17.5–22 | Close on the product | Three image strips → bracketed seed → brand | Settle on the center | Brand held | Quick contraction / 2s hold |
